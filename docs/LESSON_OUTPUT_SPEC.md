# レッスンの文字入力・録音練習仕様

## 目的と範囲

既習語を思い出して書く・声に出す機会を、各レッスンのExploreに追加する。ユーザーが今回明示依頼した任意機能であり、Phase 4全般の語彙・文法開発、認証、AIサービス、公開デプロイへは進めない。

既存の5章22レッスン・110問・最大890XP・保存スキーマ版 `1` を維持する。新しい練習は各レッスン1語、計22課題で、採点用の5問とは別に扱う。飛ばしても通常のクイズ・レッスン完了へ進める。

## 音を確認できる場所

全22レッスンのLearnの例語とExploreに、端末のタイ語合成音声を使う確認手段を設ける。Thai文字と空白の語を対象にし、子音位置を示すハイフン、音節分解の記号、Latin・IPAを含む図式は読み上げない。図式を示す場合は、下の語の練習で音を確認するよう案内する。

音声は「端末の合成音声（未監修）」と表示し、提供元への通信の可能性を示す。利用者操作で再生し、発音ラボの聞き分け練習では使用する声の名前・言語も表示する。タイ語音声がない場合は理由を伝え、別言語の声で代用しない。TTSがなくても解説・IPA・通常のクイズを利用できる。ネイティブ話者の実録音教材は未収録で、見本の発音・声調の自然さも専門家未監修。

## 課題データ

`src/data/lesson-output.ts` に `LessonOutputTask` を独立して置く。

| 項目                         | 内容                                     |
| ---------------------------- | ---------------------------------------- |
| `id` / `lessonId`            | 一意の課題IDと対応する既存レッスン       |
| `prompt` / `hint`            | 日本語の問いと任意のヒント               |
| `target` / `acceptedAnswers` | 見本のThai綴りと許容する完全一致の文字列 |
| `ipa` / `meaning`            | 一貫したIPAと日本語訳                    |
| `explanation`                | 文字・母音配置・声調等の確認理由         |
| `sourceIds` / `verification` | 出典参照と `unreviewed`                  |

課題語はそのレッスンか前提で扱った語を使い、突然未習事項を試さない。文字モードの問題・ヒントへThaiの正答文字列を埋め込まず、回答後に見本と理由を示す。教材は未検証の教材案であり、自動テストの成功を専門家監修とみなさない。

## 文字で答える

問題・ヒントを確認し、Thaiキーボードで入力して「文字の答えを確認」を押す。空欄と不正・過長入力は理由を示し、綴りが異なる場合も見本・IPA・解説で比較できる。何度でも試せ、失敗のペナルティはない。

`src/lib/answer-comparison.ts` は前後の `trim()` だけを行う完全一致比較とする。Unicode正規化、結合文字の分解・並べ替え、句読点除去、語中の空白除去はしない。入力上限は200文字。正答は「正しい綴り」と説明し、発音が正しいという判定へ言い換えない。

Macでは「システム設定 → キーボード → テキスト入力 → 編集 → ＋」からタイ語を追加し、入力メニューで切り替える。入力設定がない場合は声モードや通常の教材でも学べる。

## 声で確かめる

見本のThai・IPA・意味を表示し、端末TTSと自分の声を交互に聞き比べる。母音の長さ、息、声の高さに注意を向けるが、アプリは発音・声調を採点しない。

### ローカル録音

- 「録音を始める」を押したときだけマイクの許可を要求する。HTTPSまたはlocalhostの対応ブラウザが必要。
- `getUserMedia` / `MediaRecorder` を使用し、最大20秒で停止する。容量上限は5MB（5 × 1024 × 1024 bytes）。超過した録音は破棄し、短く取り直すよう伝える。
- 停止後は音声プレーヤーで聞き直せ、「録音を削除」で破棄できる。自動ダウンロード・アップロード・サーバー保存はしない。
- BlobとObject URLをこの画面のメモリだけで保持する。課題・モードの変更、画面離脱で破棄し、再生・録音を停止してトラック・URL・タイマーを解放する。
- マイク拒否、不在、他アプリでの使用、録音・再生エラーを説明する。許可待ちの取消しや遅れて返るイベントで、離脱後のマイクを保持しない。

録音は利用者自身の聞き比べ用で、教師・ネイティブ話者の監修済み音源ではない。「録音機能は送信しない」という説明は、このMediaRecorder機能についてのもの。

### 音声認識は別の任意機能

対応ブラウザでは `SpeechRecognition` または `webkitSpeechRecognition` を使い、話した言葉がどんなタイ文字として返るか参考表示する。開始前に、音声がブラウザ提供元のサービスへ送信される場合があり、利用条件はブラウザに依存することを伝える。利用者が「音声認識を始める」を押したときだけ開始する。

言語は `th-TH`、連続認識・途中結果は使わず、最終文字列1候補を受け取る。約9秒で終了し、取消しも可能。表示する一致・相違は、文字モードと同じ完全一致比較による参考結果である。認識の信頼度、発音の正確さ、声調の点数は算出しない。一致しても正確な発音の証明にならず、相違しても発音が誤りとは限らない。

非対応・マイク拒否・通信やサービスのエラー・時間切れでは理由を表示し、文字入力やローカル録音の聞き直しを案内する。停止・離脱後の古いイベントは画面へ反映しない。アプリは認識結果と認識用音声を保存しないが、提供元の通信を「送信なし」とは説明しない。

## 排他制御とデータの扱い

TTS、録音、音声認識を同時に実行しない。録音・認識の開始時はTTSや録音の再生を止め、マイク使用中は見本の再生を無効にする。方法を変更・画面を離脱した場合は対応するセッションを破棄する。

| 対象               | アプリ内の保持                  | 通信・評価                                                 |
| ------------------ | ------------------------------- | ---------------------------------------------------------- |
| 文字入力と綴り判定 | 現在の画面の一時状態のみ        | アプリから送信せず、XP・理解度・前提へ使わない             |
| 利用者の録音       | メモリ内のBlob / Object URLのみ | アプリから送信・永続保存せず、自動採点しない               |
| 認識文字列         | 現在の画面の一時状態のみ        | 音声はブラウザ提供元へ送信され得る。文字列の一致は参考のみ |
| 端末TTS            | 配布用の音声ファイルを作らない  | OS・ブラウザの音声提供元へ通信され得る。未監修             |
| 既存の通常クイズ   | 従来の進捗スキーマ版 `1`        | 全110問、合格80%以上、初回完了のみ最大890XPを維持          |

入力・録音・認識結果のlocalStorage、DB、学習履歴への保存は行わない。この追加機能だけを使っても、Lesson完了・XP・進級状態は変化しない。

## 確認項目と残る限界

課題と既習語の対応、22件の参照整合性、完全一致・空欄・Unicode保持、Thai TTSの対象、録音の時間・容量上限と破棄、認識の非対応・拒否・時間切れ・遅延イベント、排他制御、通常クイズと保存への非干渉を検証する。PC・スマートフォンの操作と、キーボード・ラベル・結果通知も確認する。実行結果は [VALIDATION.md](VALIDATION.md) に記録する。

自動テストで模擬したブラウザAPIの挙動と、実端末のマイク・認識・TTSの品質確認は区別する。タイ語音声や認識サービスの有無・精度は端末とブラウザに依存する。専門家による教材・IPA・音声の監修、ネイティブ話者の実録音教材、定量的な発音・声調評価は未完了。
