# Thai Learning プロダクト仕様

## 目的

日本語を母語とする成人が、タイ語の音・文字・単語・文法を関連付けて学ぶWebアプリケーション。学ぶ順序はカリキュラムで決め、短い解説と操作・演習を組み合わせる。正確な理解を、XPや演出より優先する。

## 現在の範囲：Phase 1・Phase 2

第1章「タイ語の文字と発音の基礎」の6レッスン・30問を維持し、第2章「子音44文字を整理する」の5レッスン、第3章「母音の長さと配置」の3レッスン・合計40問を追加した。全3章14レッスン・70問。1回8〜12分を目安に、文字・音・意味を関連付ける。教材は専門家の監修が未完了の教材案として表示する。

教材の全体像と学習順序は [CURRICULUM.md](CURRICULUM.md) に定義する。Phase 2の仕様は [PHASE2_SPEC.md](PHASE2_SPEC.md) を参照する。Phase 3以降の項目は予定として表示し、利用できる教材と区別する。未実装の機能に操作できそうなボタンを設けない。

| 順序 | Lesson ID            | 学習の中心           |
| ---- | -------------------- | -------------------- |
| 1    | `sounds-and-letters` | 文字と音の基本構造   |
| 2    | `first-consonants`   | 基本子音の識別と音価 |
| 3    | `breath-and-sounds`  | 有気音・無気音       |
| 4    | `vowel-length`       | 母音の長短と配置     |
| 5    | `syllable-endings`   | 音節と末子音         |
| 6    | `five-tones`         | 5声調の概要と総復習  |

第1章は ก ข ค ง จ ด ต น ม ร の10文字を入口とする。第2章で中9・高11・低24の全44子音を整理し、第3章で母音の長短と綴りを広げる。ライブラリは32母音パターンを収録するが、全ての綴り・例外を網羅した辞書ではない。初期3章で声調決定規則をすべて学び終えたとは扱わない。

## レッスンの流れ

1. **Learn — 理解する**：学習目標、前提知識、新しい概念、日本語との違い、例語を短いまとまりで読む。
2. **Explore — 確認する**：文字・母音・音節を選び、音価や構成・違いを見比べる。音声を用意できていない場合は文字・IPAによる確認と明示する。
3. **Practice — 練習する**：選択式と文字識別式の問題に答える。判定後には、正誤にかかわらず答えの理由を表示する。回答を確定する前には正解を表示しない。
4. **Review — 定着させる**：重要事項と今回の正答率を確認し、理解度を満たしたらレッスンを完了する。間違えた問題は折りたたみを開いて正答・理由・関連する学習事項を再確認し、解説に戻れる。

長い解説を演習画面へ詰め込まない。間違えた場合は短い解説を示し、再学習への導線を用意する。ハートや失敗によるXP減算は採用しない。今回の正誤確認と、将来の苦手概念を自動集計する機能は区別する。後者は未実装。

## 進行・理解度・XP

- 第1レッスンは最初から学習可能。以降は教材データの `prerequisites` に設定された全レッスンの完了で解放する。
- Practiceの正答率が80%以上なら完了できる。正答率は、その受講回の各問題に最初に確定した回答で計算する。解説を読んだ後の選び直しで正答率を上げない。
- 80%未満の場合も解説・要点を確認でき、練習を最初からやり直せる。前提条件を満たす次レッスンは、理解度を満たした完了操作後に解放する。
- XPは各レッスンの初回完了時のみ付与する。再受講では最高正答率を更新できるが、XPを重複加算しない。
- 第1章は240XP、第2・3章は330XP。全14レッスンの初回完了は合計570XP。第2章は `five-tones` を前提とし、その後も教材の前提に沿って進む。
- XPは学習継続の記録、正答率と完了状態は理解度の目安として分けて表示する。XPだけで学習を解放しない。
- 進捗は同じブラウザの `localStorage` に保存する。読み込み・書き込みができない場合は説明し、学習画面が壊れないようにする。別端末への同期、永続的なバックアップは提供しない。
- 保存対象は全問を終えた受講結果であり、レッスンの閲覧位置や途中回答は保存しない。途中で再読み込みすると、その回は最初からとなる。
- 学習日と連続学習日数はブラウザのローカル日付で記録する。実測していない学習時間は表示しない。
- 不正・破損した保存データは読み込み時に警告し、元の内容を保持する。その後に新しい受講結果を保存すると元データを置き換える。書き込み拒否の場合は保存できていない状態を伝える。
- 複数タブは更新通知と保存直前の再読み込みで同期する。厳密に同時の書き込みや別端末の同期は保証しない。
- Phase 1の既存Lesson IDと保存版 `1` を維持する。既存の第1章完了記録はそのまま使え、追加章の未完了状態だけが増える。

## タイ文字ノートと書取り

文字ノートは全44子音をUnicode字順で収録する。`ฃ`・`ฅ` は廃用字、`ฑ` は語によって初頭音が変わる字として注記する。字母名の最初の音節のIPAと、単語の初頭音・末子音のIPAを分ける。母音は基本9組の長短18形、二重母音3組の長短6形、特殊・変化形8形の32パターンを収録する。母音の `-` は子音の位置を示す図示用記号である。

書取りでは44子音と32母音パターンの用例全体を選べる。マウス・指・ペンのPointer Eventsに対応し、標準のループありフォントの薄い手本、手本なし、ガイド線、1本戻す、全消去を提供する。なぞり書きは字形への慣れを目的とし、フォントの輪郭から筆順を推定しない。手本は全体の字体設定にかかわらずループありで固定する。

`ก`・`ง`・`จ`・`ม` の4字に限り、MITライセンスの独立した手録りデータを用いたSVGの参考運筆例を提供する。これは出典の軌跡の再生であり、標準筆順は未検証・専門家監修前であることを表示する。他の40子音・全母音には未確認の筆順アニメーションを提供しない。線の本数は描いた操作の記録で、正しい画数ではない。

書取りには自動採点、筆順評価、XP、進捗保存を設けない。文字の変更・画面移動で描いた線は消える。運筆例を参照できることを、正式な筆順教材の完成と扱わない。

## 教材の品質

- 教材は画面から独立した構造化データとして保持し、出典と確認状況を記録する。
- `source-checked` は記載資料との照合を示す。専門家による教材全体の監修・保証とは区別する。照合していない内容は `unreviewed` として管理し、確認済みと表示しない。
- 現在のLesson・Character・VowelPatternは `unreviewed`。出典の候補と参照可否を記録し、教材案・未検証として表示する。公開教材としての確定には専門家による確認が必要。
- 発音はIPAを基準とし、アプリ内で方式を統一する。カタカナを正確な発音の代用としない。
- タイ文字のUnicode結合文字を不用意に分解・並べ替えない。
- 4字の参考運筆例は出典の軌跡・利用条件のみ `source-checked` とし、`standardStrokeVerified: false` を保持する。検証済みの標準筆順とは表示しない。音声素材は未収録で、機械音声をネイティブ音声として紹介しない。
- 初級で導入する声調の説明と、未実装の自動声調判定を区別する。綴りからの推測結果を正解として表示しない。

## UI / UX

落ち着いたivoryとforest greenを基調に、成人が読み続けやすい余白、十分な本文サイズと行間を用いる。達成感は小さな完了演出・進捗表示で伝える。過剰なアニメーションや競争ランキングは使わない。

PCはサイドバーで主要画面を移動し、スマートフォンは1カラムとコンパクトなナビゲーションで操作する。タッチ対象は十分な大きさを確保する。Thaiと日本語のフォントはFontsourceのnpmパッケージから自己配信し、母音記号や声調記号が上下で切れない行高を取る。

共通ヘッダーの「タイ語の字体」スイッチで、標準のループあり字体とループなし字体を切り替えられる。初期値は標準で、選択は同じブラウザに保存し、画面移動・再読み込み後も反映する。字体を切り替えても教材の文字列・発音表記・採点・進捗は変わらない。書取りの薄い手本だけは字形の一貫性のためループありに固定する。スイッチはキーボードとタッチで操作でき、保存を使用できない場合は説明を表示する。

セマンティックHTML、見えるフォーカス、キーボード操作、ラベル付きフォームを基本とする。正誤を色だけで伝えず、文字とアイコンを併用する。動きを減らす設定を尊重し、結果をスクリーンリーダーにも知らせる。

## 完成条件

- Dashboard、Roadmap、LessonをPC・スマートフォンで操作できる。
- 第1〜3章の14レッスンで解説、確認、出題、正誤・理由表示、完了、次の学習がつながる。
- 全44子音・32母音パターンを検索・参照し、書取りへ進める。書取りのマウス・タッチ入力、補助操作、参考運筆例の範囲を確認できる。
- 前提未達のレッスンはURL直接入力でも学習開始を制御する。
- 進捗とXPをリロード後も維持し、再受講でXPを増やさない。
- 型チェック、ユニットテスト、本番ビルド、主要な学習フローのE2Eテストを実行する。
- Thaiの上下の結合記号、PC・スマートフォンの表示、キーボード操作をブラウザで確認する。
- 教材の確認状況、未実装機能、ローカル保存の制約を実際の状態に合わせて説明する。
