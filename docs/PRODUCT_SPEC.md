# Thai Learning プロダクト仕様

## 目的

日本語を母語とする成人が、タイ語の音・文字・単語・文法を関連付けて学ぶWebアプリケーション。学ぶ順序はカリキュラムで決め、短い解説と操作・演習を組み合わせる。正確な理解を、XPや演出より優先する。

## 現在の範囲：Phase 1〜Phase 3

既存の第1章6レッスン、第2・3章8レッスンに、第4章「音節と声調のしくみ」と第5章「声調規則を使って読む」の各4レッスン・計40問を追加した。全5章22レッスン・110問。1回8〜12分を目安に、文字・音・意味を関連付ける。教材は専門家の監修が未完了の教材案として表示する。

教材の全体像と学習順序は [CURRICULUM.md](CURRICULUM.md) に定義する。文字と書取りは [PHASE2_SPEC.md](PHASE2_SPEC.md)、音節と声調は [PHASE3_SPEC.md](PHASE3_SPEC.md) を参照する。Part 4以降は予定として表示し、利用できる教材と区別する。Phase 4の語彙・文法機能には着手しない。未実装の機能に操作できそうなボタンを設けない。

今回、ユーザーが明示依頼した既習語の入力・録音練習を追加する。全22レッスンに1問ずつの任意練習を設けるが、既存の110問・890XP・前提・保存版 `1` は変えない。文字入力、端末TTS、ローカル録音、参考の音声認識の境界は [LESSON_OUTPUT_SPEC.md](LESSON_OUTPUT_SPEC.md) に定義する。

| 2    | `first-consonants`   | 基本子音の識別と音価 |

## レッスンの流れ

1. **Learn — 理解する**：学習目標、前提知識、新しい概念、日本語との違い、例語を短いまとまりで読む。全22レッスンのThai例語は端末のタイ語TTSで確認できる。子音位置の記号や分解の図式は読み上げない。
2. **Explore — 確認する**：文字・母音・音節を選び、音価や構成・違いを見比べる。全22レッスンに端末TTSと、既習語を「文字で答える」「声で確かめる」任意練習を設ける。非対応時も文字・IPAによる確認と通常のクイズを利用できる。
3. **Practice — 練習する**：選択式と文字識別式の問題に答える。判定後には、正誤にかかわらず答えの理由を表示する。回答を確定する前には正解を表示しない。
4. **Review — 定着させる**：重要事項と今回の正答率を確認し、理解度を満たしたらレッスンを完了する。間違えた問題は折りたたみを開いて正答・理由・関連する学習事項を再確認し、解説に戻れる。

長い解説を演習画面へ詰め込まない。間違えた場合は短い解説を示し、再学習への導線を用意する。ハートや失敗によるXP減算は採用しない。今回の正誤確認と、将来の苦手概念を自動集計する機能は区別する。後者は未実装。

## 進行・理解度・XP

- 第1レッスンは最初から学習可能。以降は教材データの `prerequisites` に設定された全レッスンの完了で解放する。
- Practiceの正答率が80%以上なら完了できる。正答率は、その受講回の各問題に最初に確定した回答で計算する。解説を読んだ後の選び直しで正答率を上げない。
- 80%未満の場合も解説・要点を確認でき、練習を最初からやり直せる。前提条件を満たす次レッスンは、理解度を満たした完了操作後に解放する。
- XPは各レッスンの初回完了時のみ付与する。再受講では最高正答率を更新できるが、XPを重複加算しない。
- 第1章は240XP、第2・3章は330XP、第4・5章は各4レッスン×40XPで320XP。全22レッスンの初回完了は合計890XP。第4章は `vowel-compounds` を前提とし、その後も教材の前提に沿って進む。
- XPは学習継続の記録、正答率と完了状態は理解度の目安として分けて表示する。XPだけで学習を解放しない。
- 進捗は同じブラウザの `localStorage` に保存する。読み込み・書き込みができない場合は説明し、学習画面が壊れないようにする。別端末への同期、永続的なバックアップは提供しない。
- 保存対象は全問を終えた受講結果であり、レッスンの閲覧位置や途中回答は保存しない。途中で再読み込みすると、その回は最初からとなる。
- 学習日と連続学習日数はブラウザのローカル日付で記録する。実測していない学習時間は表示しない。
- 不正・破損した保存データは読み込み時に警告し、元の内容を保持する。その後に新しい受講結果を保存すると元データを置き換える。書き込み拒否の場合は保存できていない状態を伝える。
- 複数タブは更新通知と保存直前の再読み込みで同期する。厳密に同時の書き込みや別端末の同期は保証しない。
- Phase 1・2の既存14個のLesson IDと保存版 `1` を維持する。既存の完了・XP・回答履歴はそのまま使え、追加章の未完了状態だけが増える。
- 発音・声調ラボは補助教材であり、操作によるXP付与・完了記録・前提解放はない。
- 任意の入力・録音・音声認識は成績や前提判定から独立する。入力値、録音、認識文字列は保存しない。文字の一致や認識結果を、発音・声調の習熟度として扱わない。

## タイ文字ノートと書取り

文字ノートは全44子音をUnicode字順で収録する。`ฃ`・`ฅ` は廃用字、`ฑ` は語によって初頭音が変わる字として注記する。字母名の最初の音節のIPAと、単語の初頭音・末子音のIPAを分ける。母音は基本9組の長短18形、二重母音3組の長短6形、特殊・変化形8形の32パターンを収録する。母音の `-` は子音の位置を示す図示用記号である。

書取りでは44子音と32母音パターンの用例全体を選べる。マウス・指・ペンのPointer Eventsに対応し、標準のループありフォントの薄い手本、手本なし、ガイド線、1本戻す、全消去を提供する。なぞり書きは字形への慣れを目的とし、フォントの輪郭から筆順を推定しない。手本は全体の字体設定にかかわらずループありで固定する。

`ก`・`ง`・`จ`・`ม` の4字に限り、MITライセンスの独立した手録りデータを用いたSVGの参考運筆例を提供する。これは出典の軌跡の再生であり、標準筆順は未検証・専門家監修前であることを表示する。他の40子音・全母音には未確認の筆順アニメーションを提供しない。線の本数は描いた操作の記録で、正しい画数ではない。

書取りには自動採点、筆順評価、XP、進捗保存を設けない。文字の変更・画面移動で描いた線は消える。運筆例を参照できることを、正式な筆順教材の完成と扱わない。

## 発音・声調ラボと判定範囲

登録済みの1音節語を選ぶか、タイ語を完全一致で検索する。初頭子音・母音・末子音、IPA・訳を独立したカタログから表示し、子音クラス、生音節・死音節、記号・母音長、声調の理由を順に説明する。未登録語・複数音節の語には「この語はまだ解析できません」と表示し、発音・声調を推測しない。Unicode文字列の分割や並べ替えで音節を生成しない。

5声調は日本語名・IPA・Chao五度式と模式図で比較する。模式図は録音の実測ピッチではなく、話者・文脈による差を含む概略として表示する。手動条件の変更は、指定されたクラス・長短・末音・記号・初頭構造へ規則を適用する操作であり、任意の綴りの自動解析ではない。

真正子音連続は先頭のクラス、確認済みのห นำは高子音、限定的なอ นำは中子音として扱う。適用できる綴りかどうかは登録分析側で確認し、一般の子音の並びに適用しない。支持しない条件や不正な分析情報は判定不能にする。辞書補完は確認状況・出典・理由を必須とし、通常規則との違いを表示する。現在の32登録語には辞書例外の指定はない。

ネイティブ話者の実録音教材は未収録。端末にタイ語音声がある場合だけ、Web Speech APIで確認・任意の聞き分け3問を利用できる。「端末の合成音声（未監修）」、声の名前・言語・通信の可能性を表示する。タイ語音声がない場合は利用不可を説明し、他言語で代用しない。未確認の機械音声をネイティブ発音として提供せず、合成音声の結果をXP・進級条件に使わない。

## 任意の文字入力・録音練習

各レッスンで扱う語または前提で学んだ語を、Exploreで1語ずつ練習する。文字入力は前後の空白以外を変更せず、Unicode結合文字、語中の空白、記号を保持した完全一致で綴りを判定する。回答後は見本・IPA・理由を表示し、何度でも試せる。

声の練習は見本とIPAを示し、端末TTSと自分の録音を聞き比べる。MediaRecorderによる録音は最大20秒・5MB、画面内のメモリのみで保持し、再生・削除できる。アプリから送信せず、モード切替・画面離脱で破棄する。見本音声・教材は専門家未監修であり、録音を自動採点しない。

別の任意機能としてWeb Speech Recognitionを `th-TH`、約9秒の上限で呼び出す。ブラウザ提供元へ音声が送信される可能性を、利用者が開始する前に表示する。返された文字列だけを見本と比較し、参考の一致・相違として示す。発音、声調、認識の信頼度を点数化しない。

TTS・録音・音声認識は相互に排他する。非対応、権限拒否、機器・認識エラーでも文字入力や録音の聞き直し、既存の解説・クイズへ戻れる。自動でマイクを開始しない。詳細は [LESSON_OUTPUT_SPEC.md](LESSON_OUTPUT_SPEC.md) を参照する。

## 教材の品質

- 教材は画面から独立した構造化データとして保持し、出典と確認状況を記録する。
- `source-checked` は記載資料との照合を示す。専門家による教材全体の監修・保証とは区別する。照合していない内容は `unreviewed` として管理し、確認済みと表示しない。
- 現在のLesson・Character・VowelPattern・SyllableEntryは `unreviewed`。出典の候補と参照可否、基本声調表など実際の照合範囲を記録し、教材案・未検証として表示する。規則実装のテスト成功を個々の語義・IPAの監修完了と混同しない。公開教材としての確定には専門家による確認が必要。
- 発音はIPAを基準とし、アプリ内で方式を統一する。カタカナを正確な発音の代用としない。
- タイ文字のUnicode結合文字を不用意に分解・並べ替えない。
- 4字の参考運筆例は出典の軌跡・利用条件のみ `source-checked` とし、`standardStrokeVerified: false` を保持する。検証済みの標準筆順とは表示しない。音声素材の利用条件と語の対応は別途確認する。
- 声調判定は確認済みの分析条件を使う。未登録の綴りからの推測結果を正解として表示しない。

## UI / UX

落ち着いたivoryとforest greenを基調に、成人が読み続けやすい余白、十分な本文サイズと行間を用いる。達成感は小さな完了演出・進捗表示で伝える。過剰なアニメーションや競争ランキングは使わない。

PCはサイドバーで主要画面を移動し、スマートフォンは1カラムとコンパクトなナビゲーションで操作する。タッチ対象は十分な大きさを確保する。Thaiと日本語のフォントはFontsourceのnpmパッケージから自己配信し、母音記号や声調記号が上下で切れない行高を取る。

共通ヘッダーの「タイ語の字体」スイッチで、標準のループあり字体とループなし字体を切り替えられる。初期値は標準で、選択は同じブラウザに保存し、画面移動・再読み込み後も反映する。字体を切り替えても教材の文字列・発音表記・採点・進捗は変わらない。書取りの薄い手本だけは字形の一貫性のためループありに固定する。スイッチはキーボードとタッチで操作でき、保存を使用できない場合は説明を表示する。

セマンティックHTML、見えるフォーカス、キーボード操作、ラベル付きフォームを基本とする。正誤を色だけで伝えず、文字とアイコンを併用する。動きを減らす設定を尊重し、結果をスクリーンリーダーにも知らせる。

## 完成条件

- Dashboard、Roadmap、LessonをPC・スマートフォンで操作できる。
- 第1〜5章の22レッスンで解説、確認、出題、正誤・理由表示、完了、次の学習がつながる。
- 全44子音・32母音パターンを検索・参照し、書取りへ進める。書取りのマウス・タッチ入力、補助操作、参考運筆例の範囲を確認できる。
- 前提未達のレッスンはURL直接入力でも学習開始を制御する。
- 進捗とXPをリロード後も維持し、再受講でXPを増やさない。
- 既存14レッスンの進捗から第4章を解放でき、追加8レッスンで320XP、全体890XPを重複なく記録できる。
- 発音・声調ラボで登録語の分解・理由を確認でき、未知語・未対応条件は発音を推測せず説明する。5声調の表示と手動条件変更をキーボードでも操作できる。
- 全22レッスンでThai例語とExploreのTTS確認、1語の任意入力練習へ進める。図式の読み上げを避け、未監修・非対応を説明する。
- 文字の即時判定・理由、録音の再生・削除・離脱破棄、参考の音声認識と通信説明、エラー時の代替導線を確認する。任意練習でXP・前提・保存内容が変化しない。
- 型チェック、ユニットテスト、本番ビルド、主要な学習フローのE2Eテストを実行する。
- Thaiの上下の結合記号、PC・スマートフォンの表示、キーボード操作をブラウザで確認する。
- 教材の確認状況、未実装機能、ローカル保存の制約を実際の状態に合わせて説明する。
