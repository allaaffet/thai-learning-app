# Phase 3 追加レッスン

## 対象と確認状態

Phase 2 の全14レッスンに、以下の8レッスンを追加する。既存のID・章所属・完了条件を変更しない。新規Lessonはすべて10分・40XP・5問とし、1問は5つの選択肢から選ぶ。初回確定回答で80%以上の正答率なら完了できる。誤答も理由を表示し、XPは初回完了時だけ加算する。

新規の教材データは `src/data/phase-three.ts` に置く。規則の出典参照IDは `thai-tone-rules-phase3`。語彙の訳・IPA・教材としての説明を含む専門家の総合監修は完了していないため、Lessonの `verification` は `unreviewed` とする。規則表の照合を、教材の正確性保証や話者の音声評価と同一視しない。

表記は既存教材に合わせ、中平調 /˧/・低調 /˨˩/・下降調 /˥˩/・高調 /˦˥/・上昇調 /˩˩˦/ とする。これらは代表的な輪郭を示す概略であり、すべての話者・文脈で固定した音高になるという意味ではない。母音長は /ː/、有気音は /ʰ/、未開放の末子音は /p̚ t̚ k̚/ で表す。

## 規則の範囲

### 生音節と死音節

- 生：長母音で終わる音節、または /m n ŋ j w/ で終わる音節。
- 死：/p̚ t̚ k̚/ で終わる音節、または短母音と声門閉鎖 /ʔ/ で終わる基本音節。
- 短母音の `กิน` は /n/ 終わりなので生、長母音の `มาก` は /k̚/ 終わりなので死。母音長だけで決めない。
- `ใจ` などは母音綴りに /j/ を含むため、末子音字の有無だけで判断しない。

### 声調記号なし

| 有効クラス | 生     | 死・短母音 | 死・長母音 |
| ---------- | ------ | ---------- | ---------- |
| 中         | 中平調 | 低調       | 低調       |
| 高         | 上昇調 | 低調       | 低調       |
| 低         | 中平調 | 高調       | 下降調     |

### 声調記号あり

| 有効クラス | ่ マイエーク | ้ マイトー | ๊ マイトリー       | ๋ マイチャッタワー |
| ---------- | ------------ | ---------- | ------------------ | ------------------ |
| 中         | 低調         | 下降調     | 高調               | 上昇調             |
| 高         | 低調         | 下降調     | 基本表では扱わない | 基本表では扱わない |
| 低         | 下降調       | 高調       | 基本表では扱わない | 基本表では扱わない |

`โต๊ะ` は中子音・死音節だが、マイトリーがあるので高調。無記号の死音節規則を当てはめない。基本表で扱わない組み合わせを、すべて誤字と断定したり、中子音の表から推測したりしない。外来語・くだけた綴りなどの個別情報を優先する。

### 有効クラス

- 真の子音連続：`ปลา` の ป、`ครู` の ค など、先頭子音のクラスを用いる。
- ห นำ：`หนู`・`หมา` は実際の初頭音が /n/・/m/ のまま、高子音の声調規則を使う。ห を独立した /h/ として発音しない。
- อ นำ：`อย่า`・`อยู่`・`อย่าง`・`อยาก` に限定して、中子音の規則で扱う。すべての อ 始まりへ一般化しない。
- 字が2つ続くことだけでは、真の子音連続・先行子音・省略母音・黙字の型を断定しない。

## 単語と演習の設計

主な規則適用例は `กา`・`กิน`・`กะ`・`ขา`・`ขุด`・`มา`・`คน`・`รัก`・`คิด`・`มาก`・`พูด`・`ป่า`・`ป้า`・`ค่า`・`ค้า`・`โต๊ะ`・`จ๋า`・`ปลา`・`ครู`・`หนู`・`หมา`・`อย่า`・`อยาก`。意味のある語の中で条件を確かめる。

音の比較では、`ปา /paː˧/` と `พา /pʰaː˧/` は有気・無気、`ขัน /kʰan˩˩˦/` と `ขาน /kʰaːn˩˩˦/` は母音長を比べる。`กิน` と `คิด` のように初頭・末子音・声調も異なる組は最小対として提示しない。

選択式問題は、単に声調名を答える問題に加え、条件と規則の組を選ぶ問題、記号がある場合の分岐を選ぶ問題、辞書が必要な場面を判断する問題を含める。全問に正答の理由と関連概念を持たせる。

音声素材を使う場合は、音声側の出典・ライセンス・話者情報・確認範囲と結び付ける。文字・IPAの比較問題を解いただけで、リスニングや発音採点を終えたとは扱わない。音声の実装・素材確認は、教材データの `unreviewed` を自動で解除する根拠にはしない。

## 判定の限界

規則適用では、音節構造・有効クラス・声調記号・母音長・末子音などの入力が確認されている必要がある。任意のThai文字列の音節分解や、省略母音・特殊綴り・例外の完全解析を保証しない。未知の語で必要な条件が分からなければ、推測を正解として表示せず、辞書情報による補完か判定保留を選ぶ。

高度な文章解析、録音の自動採点、自由会話、SRS、認証・クラウド同期は、この8レッスンの実装範囲に含めない。
