# 本編の冒険とミックス練習

## ねらい

学習者は「次のミッション」を選び、発見・音と文字の確認・思い出す問題を1画面ずつ進める。新しいことだけを順番に読み続ける構成から、既習内容が少しずつ戻ってくる構成へ変える。学ぶ順序と前提知識は既存のカリキュラムで管理し、ゲーム内の見た目と教育上の進行を分ける。

教材は既存の7章30レッスン・150問を使う。Thai・IPA・意味・解説・出典・確認状態を新しく生成せず、初回完了の合計1210XPと保存版 `1` を引き継ぐ。教材は引き続き専門家監修前の教材案である。

## 入口と画面

| URL | 役割 |
| --- | --- |
| `/` | 次に遊ぶミッションを主な入口にし、文字練習・会話・単語復習にも進める |
| `/play` | 前提に沿った冒険の道。次の1つ、完了済み、これからのミッションを視覚的に示す |
| `/play/[lessonId]` | 新しい内容と既習問題を混ぜた本編ミッション |
| `/play/mix` | 完了済みの内容から最大6問を選ぶ、任意のミックス練習 |
| `/roadmap` | 部・章・レッスンの構造と前提を確認するカリキュラム |
| `/lessons/[lessonId]` | 4段階の教科書形式。詳しい解説、比較、入力・録音、通常の受講を維持する |

冒険の道は既存の完了記録から状態を決める。前提未達のノードには開始リンクを付けず、URLを直接開いた場合も同じ前提を確認する。進捗の読込みが終わるまでは開始できない。章の詳細は必要に応じて開き、現在地と次にできることを先に示す。

## ミッションの組み立て

開始時に出題列を固定する。進行中の再描画や別タブの記録更新で、表示中の問題を勝手に置き換えない。

1. 現在のレッスンの解説ブロックと確認用の例を、1枚ずつ交互に提示する。本文・注意・補足・IPAは既存の内容を参照できる形で保持する。
2. その合間に、完了済みの既知レッスンから最大2問を混ぜる。未完了・前提未達・未知IDのレッスンや現在の新出問題は使わない。
3. 現在の解説と例を全て提示した後、現在の課の確認5問（`core`）に答える。画面では「チェックポイント」と示す。教材データには各解説と各問題の対応がないため、配列位置から推測して未説明の問題を早めない。
4. 少し間を空けて、現在の問題から2問をもう一度思い出す。選択肢の位置も変え、位置だけの暗記を避ける。
5. 間違えた問題は最後に1回だけ再挑戦する。同じ問題の再挑戦を重ねて追加せず、終わりのある練習にする。

復習候補は、本編に保存されたその問題の最新回答が誤答だったものを優先し、学習範囲の広がりと古さも使って選ぶ。同じ内容だけに偏らないよう、開始時のseedで候補・選択肢の順序を変える。これは画面内の出題選択であり、新しいSRSの予定や記憶確率ではない。

復習問題には出題元のレッスン名を表示する。問題文の「この課」が現在の新しい課を指すと誤解されないようにし、元の説明を新しいタブで参照できるようにする。

1レッスン全体は従来の8〜12分程度を目安とする。操作単位は小さなカードにするが、実測せず「必ず数分で終わる」と約束しない。制限時間、ハート、失敗によるXP減算、無限の解き直しは設けない。

## 採点と保存

- 現在の課の確認5問（`core`）それぞれの初回確定回答だけを、元のLesson ID・Exercise IDで保存する。先に既習問題が出るため、画面に最初に出る5問という意味ではない。確認5問の初回回答で4問以上正解すると完了でき、XPはそのレッスンの初回完了だけに付与する。
- 途中の既習問題、思い出す2問、再挑戦の正誤はその画面内の練習情報。確認5問の初回回答による成績を上書きせず、XP・前提解放・SRS予定・日次クエスト・バッジにも追加しない。
- 終了時の明示的な記録操作だけで既存の `LearningProvider.finishLesson` を呼ぶ。解説の閲覧、途中回答、再読み込み、結果画面の表示だけでは記録しない。同じ回の二重操作で重複保存しない。
- 合格できなかった回も確認5問の初回回答を記録できる。練習内で答え直して合格に変えず、必要に応じて新しい受講回を始める。
- 保存キー・版は追加しない。途中のカード位置、再挑戦、選択した回答・入力の生データは永続保存しない。再読み込みするとその回の最初からになる。
- 成績は「確認5問の初回正解」、完了条件は「確認5問の初回回答で4問以上正解」と示す。獲得XP、今回進めたカード数、思い出す練習の回数は別に示す。ゲームの達成表示を習熟度・発音能力の保証にしない。

## ミックス練習

`/play/mix` は前提を満たして完了した既知レッスンだけから、異なる問題を最大6問選ぶ。完了済みのレッスンがない場合は最初のミッションへ案内する。間違えた問題の再挑戦も各1回までとし、練習結果はその画面内に留める。

「もう一度」で新しい組み合わせを作る場合は画面内のseedを変える。XP、受講回数、学習日、SRS、クエスト、バッジ、保存データへは書き込まない。復習への取り組みと、本編の完了を区別して表示する。

## 音声・表示・操作

既存のThai音声だけをユーザーの明示操作で再生する。未監修と通信の説明を操作前に参照できるようにし、ページ表示・次カード・答えの展開では鳴らさない。母音配置の図式・未登録の綴りから読みを生成しない。音声を利用できなくても文字・IPAで続けられる。

正誤と理由は回答直後に示し、演出で隠さない。アイコン・文字・状態を併用し、色だけで判定を伝えない。キーボード、見えるフォーカス、画面移動時の見出し、320pxと文字200%の折返し、動きを減らす設定を確認する。

効果音は各問題カードの初回確定回答で、既存の正解・誤答音を1回だけ鳴らす。同じ問題の想起・再挑戦は別カードとして扱い、同じカードの二重操作では重ねない。完了音は明示的な合格記録を既存の `finishLesson` が受け付けた場合だけとし、表示・移動・答えの展開・振り返り表示・ミックス終了、結果が受け付けられず例外になる場合は鳴らさない。localStorageへ書き込めなくても、このタブのメモリ内で受け付けた完了は完了音の対象とする。その場合は保存できていない警告を残し、保存済みとは表示しない。初期オフ・音量設定・教材音声の優先を守り、新しい音源や依存は増やさない。詳細は [SOUND_EFFECTS.md](SOUND_EFFECTS.md) を参照する。

## 検証する境界

全30課の解説・確認項目・元の確認5問の保持、教える前の新出問題の除外、既習候補の前提、seed再現、2問の想起と再挑戦の上限、選択肢の文字列・正答の保持をユニットで確認する。E2Eでは確認5問それぞれの初回回答・80%・初回XP・明示保存・二重操作、混在する復習の非保存、前提未達、読み直し・旧教科書、音声の明示再生、PC・スマホ・文字拡大・キーボードを確認する。実行結果は [VALIDATION.md](VALIDATION.md) に記録する。
