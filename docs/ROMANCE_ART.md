# 恋するタイ語のイラスト

`public/romance/cast.png` は、2026-11-02に利用者の依頼でOpenAIの画像生成ツールを使って作成した、このプロジェクト用の二次元イラストです。実在人物の写真や既存作品のキャラクターを参照画像として使用していません。

1536×1024pxの画像を3列×2行に表示します。上段はマリ・リン・ダーオ、下段はアルン・キエット・ニランです。全員が27歳以上の架空の成人という設定で、年齢・性格は `src/data/romance.ts` に記載しています。

初回の生成画像を参照し、同じ画像生成ツールで人物のバリエーションを増やして採用しました。女性陣は柔らかく華やかな少女漫画寄り、男性陣は線や陰影が少しシャープな大人の恋愛漫画寄りにしています。マリは長いウェーブ、リンは黒髪ボブと角形の眼鏡、ダーオは短い赤茶の髪と明るい表情。アルンは短髪と広い肩、キエットは整えた髪と丸形の眼鏡、ニランは長めのウェーブと柔らかな雰囲気に分けています。顔立ち・肌の色・体格・衣装にも違いを持たせています。

生成時には、成人の恋愛ゲームの画風、普段着、バンコクのカフェをイメージした背景、文字やロゴのない6区画を指定しました。生成結果の顔・衣装・区画を目視で確認して採用しています。画像は端末合成音声の話者や実在の会話相手を表すものではありません。

## 表情の追加（2026-11-03）

同じ6人の物語の反応を表すため、採用済みの `cast.png` を参照画像として、同じ画像生成ツールで3枚の表情差分を生成しました。すべて1536×1024px・3列×2行で、元の人物と同じ配置を使います。

| 表情ID | ファイル | 台本内の使い方 |
| --- | --- | --- |
| `neutral` | `public/romance/cast.png` | 通常の紹介や導入 |
| `happy` | `public/romance/cast-happy.png` | 言葉が伝わったときの笑顔、楽しい場面 |
| `thoughtful` | `public/romance/cast-thoughtful.png` | 考える、相手の話に耳を傾ける場面 |
| `concerned` | `public/romance/cast-concerned.png` | 優しく問い直す、言い直しを助ける場面 |

元画像を含めて6人×4種類、24の人物表現になります。採用時に6人の顔・髪・衣装・順序と成人らしい外見の対応、表情の違い、6区画の境界を目視で確認しました。表情差分のPNGは生成結果をコピーして配置し、画像自体の編集や切り分けは行っていません。元の生成物は作業環境の `generated_images` に保持しています。

表情は決められた物語の演出です。実際の学習者の発音や感情を読み取るものではなく、誤答を怒り・軽蔑・羞恥で罰するためには使いません。新しい表情も、教材や端末合成音声が監修済みである根拠にはしません。実画面での切替・画像配信・狭い画面の検証結果は [VALIDATION.md](VALIDATION.md) に記録します。

アプリでは画像自体を加工せず、区画ごとの表示窓とNext.jsの画像配信で表示します。新しい画像を追加・差し替える場合も、成人の設定、元画像の由来、人物との対応と表示の欠けを確認してください。
