# Phase 2 教材データの設計と確認記録

## 対象範囲

第1章の10子音のID・発音例を維持し、文字ライブラリに全44子音を収録します。Unicodeの字順を使い、中子音9・高子音11・低子音24に分類します。現在使われない `ฃ` と `ฅ` も44文字の一部として残し、現代の通常の単語に使う文字とは区別します。母音字の `ฤ`・`ฦ`、省略記号の `ฯ` は44子音に数えません。

母音は、基本9組の長短18形、二重母音3組の長短6形と、特殊形・末子音前の綴りの変化8形、計32形を扱います。全ての綴り・例外を網羅した辞書ではありません。母音の図示に使う `-` は子音を置く場所で、単語の一部ではありません。二つの `-` を含む変化形は最初が初頭子音、最後が末子音の位置です。音節末の子音がある綴りは図示と注記を合わせて読みます。

## データの分離

- `src/lib/alphabet-types.ts`: 子音の利用状況・Unicode名・導入レッスンと、母音パターンの型。
- `src/data/alphabet.ts`: 44子音と母音パターン、出典情報。画面や採点処理から独立。
- `src/data/alphabet.test.ts`: 字数、クラス別数、字順、ID、出典、長短ペアの整合性を検査。
- `src/data/phase-two.ts`: 第2章5レッスン・第3章3レッスンの解説・探索・40問。
- `src/data/course.ts`: 既存6レッスンと追加8レッスンの統合。保存済みのIDは変更しません。
- `src/data/course.test.ts`: 章・出典・前提の参照、演習前の文字導入、IPAの一貫性、既存進捗からの継続と570XPの上限を検査。

子音の `ipa` は字母名の最初の音節、`initialIpa` は音節初頭の子音、`finalIpa` は末子音として使う場合の基本音です。`finalIpa` がない文字を、どの単語でも末子音として読めるとは扱いません。`ฑ` には語によって /d/ と /tʰ/ が現れることを注記します。

`introducedInLessonIds` は実際に導入するレッスンのIDです。既存の10字は第1章の導入IDも維持し、44字すべてに第2章で整理し直すレッスンを結び付けています。ライブラリを開いたことやXPだけでは文字を習得済みと判定しません。

## 正確性と素材

2026-10-18にUnicode Consortium公式GitHubのUnicode 16.0 NamesListをHTTPSで取得し、44子音の文字名とコードポイント、および掲載パターンに使用する母音記号のコードポイントを照合しました。取得した全文のSHA-256は `6a299e9259d07c2a941fdc967e2117e1246d56aa4e133caff86dfc0845715679` です。照合はUnicode名・文字コードに限ります。

IPA・声調・日本語訳・用例・子音クラス・母音の分類を専門家が監修した状態ではありません。全データは `unreviewed`（教材案・専門家レビュー前）を維持します。出典が付いていることを発音まで検証済みという意味には使いません。IPAは既存教材と同じChao式の声調文字を使います。実例のIPAは音節全体を示し、母音パターンのIPAは声調を含まない母音部分です。

短母音の開音節に声門閉鎖音が生じる場合は、実例のIPAに /ʔ/ を示します。母音長の比較は声調まで同一であるという意味ではありません。`เ-ียะ`・`เ-ือะ`・`-ัวะ` は使用頻度が低く、掲載例の一般性を注記します。`เกือะ` は綴りと音を比べるための音節で、日常語としての語義は付けず、単語クイズの正解にも使用しません。声調の自動判定・音声の聞き分けは本フェーズの対象に含めません。

筆順・手本は別の独立データで管理します。この一覧の字形やフォントから筆順を生成しません。検証済みの筆順素材がない文字について、正しい書き順を表示したり自動採点したりしません。

## 公開前に必要なレビュー

1. タイ語教育の専門家による44字の呼び名、初頭音、末子音、クラスの照合。
2. 辞書・音韻資料に基づく全用例の意味・IPA・声調の確認。
3. 低頻度の短い二重母音例、歴史的文字、特殊綴りの説明の確認。
4. 日本語話者が「字母名」「子音音」「母音パターン」「実際の単語」を混同しないかの確認。
