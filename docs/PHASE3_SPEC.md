# Phase 3：発音・声調の学習

ユーザーの明示依頼に基づき、Phase 1・2の14レッスンと保存版1を保ちながら、音節と声調を体系的に学ぶ機能を追加する。Phase 4以降には自動着手しない。

## 学習順序

第4章「音節と声調のしくみ」は、初頭子音・母音・末子音、生音節・死音節、無記号の中／高子音、低子音の死音節と母音長の4レッスン。第5章「声調規則を使って読む」は、声調記号、先行子音と子音連続、音の対立、規則の総合適用の4レッスンとする。

最初の `syllable-parts` は既存 `vowel-compounds` を前提とし、以降は連続した前提を持つ。各レッスンはLearn / Explore / Practice / Review、5問の選択・文字識別、誤答理由と要点を備える。各40XP、追加320XP、全22レッスンで890XP。既存の14ID・570XP・回答履歴を初期化しない。必須の5問は表記による演習とし、端末合成音声の任意練習は進級条件から独立させる。

## 声調判定の境界

`src/lib/tone-engine.ts` はUI、React、ブラウザ、教材データに依存しない純粋モジュール。子音クラス、母音長、末子音種別、声調記号、確認済みの初頭構造を入力し、判定結果と理由を返す。

- 無記号・生死・3クラス・低子音の母音長を扱う。声調記号はクラスとの対応を扱い、支持できない組み合わせは判定不能とする。
- 真正子音連続では先頭のクラス、確認済みのห先行では高子音扱い、限定されたอ先行語では中子音扱いという解析情報を受け取る。任意の綴りに機械的に一般化しない。
- 辞書の補完は通常規則と区別し、出典・確認状況と例外の理由を保持する。
- 汎用のタイ語形態素解析・任意語の音節分割は今回実装しない。登録した単音節語のみ独立カタログで分解を保持し、未登録語は「まだ解析できません」と示す。Unicode結合文字を分解・並べ替えない。
- 5声調の図は概略的な高低の模式図。録音音声の実測ピッチや、全話者共通の固定曲線として扱わない。

## 発音・声調ラボ

`/pronunciation` で登録語の初頭・母音・末尾とIPAを確認し、子音クラス→生死→記号・母音長→声調の理由を追える。条件を手動で変更する練習は「入力した条件に基づく結果」と明示し、綴りの自動解析と混同しない。5声調を図と日本語で比較し、学習ロードマップへ戻れる。ラボの閲覧はXPやレッスン解放の条件に使わない。

## 音声の品質と利用条件

音声はファイル、出典、著作者、明示されたライセンス、語の対応、録音／合成の区別、確認日を記録する。コードのライセンスが第三者の音声にも適用されると推測しない。再配布条件を確認できない素材、架空ファイル、未確認の機械音声をネイティブ発音として扱う機能は追加しない。到達できない資料と確認済み資料は調査記録で分ける。

## 画面とアクセシビリティ

既存のforest green／ivoryと字体切替を維持する。発音ラボへのナビゲーションを追加し、スマートフォンでもボタン・選択肢・図が収まる構成にする。図の声調は色だけでなくラベル・IPAと説明文で区別する。再生は自動で始めず、音声エラー、未対応、未知語を状態として説明する。

## 検証

規則の全主要分岐・支持しない組み合わせ・実行時の不正入力・辞書補完・登録語との整合をユニットテストで確認する。8レッスンの実回答、旧進捗継続、XP重複防止、ラボの既知語／未知語、PC・スマートフォン表示、合成音声の能力判定と再生操作をPlaywrightで確認する。実録音声は未収録であり、合成音声のAPIテストを音声品質の検証とは扱わない。テストの成功を教材の専門家監修完了と混同しない。

## 音声に関する実装上の判断

調査した候補から再配布可能な実録音声を確保できなかったため、録音素材は収録しない。端末のThai音声を使う任意機能を「端末の合成音声（未監修）」として提供する。声の非同期取得、音声がない場合、再生の停止・完了・エラーを扱う。使用する声の名前・言語と、通信の可能性を表示し、タイ語の声がない場合は他言語で代用しない。

任意の聞き分け3問は正解・IPA・理由を確認できるが、XPやレッスンの解放には用いない。音声を最後まで聞く前や再生エラー時は答えを確認できない。録音教材の追加と専門家による音声監修は残課題とする。
