# Phase 4：語彙・文法・復習をつなぐ

## 完成する体験

文字と声調の基礎を終えた学習者が、短い文で意味を伝え、覚えたい語を選んで日を空けて復習できるようにする。ユーザーの明示依頼に基づく開発で、認証・外部DB・AI会話・有料サービス・公開デプロイは含めない。

既存22レッスン・110問・890XPと進捗保存スキーマ版 `1` を保つ。追加8レッスンは各5問・40XPで、全30レッスン・150問・初回完了の合計1210XPになる。空欄入力・語句の並べ替えも必須クイズに含め、理由を表示する。合格80%、前提レッスン、再受講のXP重複防止を維持する。

最初は `tone-reading-review` の完了が前提で、その後は順に進む。Part 5・6の入門を実装し、両Partのあらゆる文法・語彙を網羅したとは扱わない。Learn → Explore → Practice → Review、8〜12分を保ち、解説・用例に出た内容から解けるようにする。

独立した語彙40語、文法8項目はThai・日本語・IPA、音節区切り、短い例文、語句の文法的役割、関連レッスン、出典・確認状況を持つ。未監修の説明・訳・用法を保証済みと表示しない。資料の実確認範囲は `PHASE4_SOURCES.md` に記録する。辞書の区切りを保持し、任意入力の自動解析とは区別する。

## 画面

- `/vocabulary`：日本語・Thai検索、カテゴリー、例文・IPA・音節、端末TTS、復習への登録と登録済み表示。
- `/grammar`：項目検索と参照、語順の型、日本語との違い、例文の役割、関連語彙・レッスン。前提未完了のレッスンは条件を案内する。
- `/review`：期限の来た登録語を最大20語ずつ出題し、答えの表示後に自己評価する。期限前だけなら次の予定、未登録なら単語帳を案内する。
- Dashboard：今日の復習件数、登録語数と単語帳・復習への導線。
- Progress：既存のXP・正答率・完了に加え、復習記録、直近の解答、最新回答から集計する苦手概念と関連レッスン、直近7日の活動。

森林色とivoryを保ち、スマートフォンは1カラムとタッチ操作。増えるナビゲーションはモバイルで横スクロール可能にする。Thaiの字体切替を単語・入力・例文にも適用する。

## 演習と保存

Exerciseを判別できる型で拡張し、選択・文字識別・空欄・並べ替えを分ける。空欄は前後空白を除いた完全一致で、Thai結合文字の正規化・記号除去をしない。並べ替えは語句IDの順序を調べ、未知ID・重複・欠落を正答と認めない。複数の自然な語順が成立する場合は、設問の文脈を明確にする。

判定はUIから独立させる。`ExerciseAttempt.selectedOptionId` に入力形式の正答は正答ID、誤答は固定識別子を記録する。文字入力そのものと録音は保存しない。既存の任意音声練習もXP・必須正答率には加算しない。

## 間隔反復学習（SRS）

利用者が単語帳で選んだ語だけを登録し、新規登録はすぐ出題可能。Thaiを見て意味を思い出し、答えの表示後に次を選ぶ。

| 自己評価   | 次の予定                        |
| ---------- | ------------------------------- |
| もう一度   | 10分後、最初の段階へ戻す        |
| 迷った     | 1日後、段階を進めない           |
| 思い出せた | 1・3・7・14・30・60日、上限60日 |

固定間隔を使う簡単な方式で、記憶確率を推定する学習モデルではない。XP・発音採点・習熟度と区別する。二重押しで同じ回答を重複記録しない。日時はISO、表示は端末の日時。開きっぱなしの画面も定期更新する。各回の対象は開始時に固定し、今答えた語を同じ回で繰り返さない。

独立した `thai-learning.review.v1` にカードの予定・段階・回数と直近1000回の履歴を保存する。元の進捗は書き換えない。不正JSON・未知版・日時・未知語IDを検査し、壊れた元データを自動上書きしない。保存不可時は通知し、タブ内のメモリで続ける。通常の複数タブ操作は書き込み前の再読込とstorageイベントで取り込む。原子的なクラウド同期は含めない。
