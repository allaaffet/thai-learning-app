# 三人から恋されるストーリー

## 遊び方

街のデート編と、社会人の大学夜間講座を舞台にしたキャンパス編で、三人が主人公を同時に誘う群像型の恋愛を楽しむ。男性主人公にはマリ・リン・ダーオ、女性主人公にはアルン・キエット・ニランが登場する。全員27〜32歳の架空の成人で、二人だけの場面にも他の相手が現れ、隣席・放課後・夜の予定・学園祭の約束をめぐって掛け合う。

相手一覧の「三人からのお誘い」で、誰に応えるかを選ぶ。本人と他の二人の反応を見て、解放済みの個人エピソードへ進める。「みんなと話す」では短い群像シーンを読み、その後から個人の誘いを選べる。ひとりに絞る必要はなく、三人の物語を並行して進められる。群像シーンを読むだけで好感度やXPを加算せず、通常の会話レッスンを終えて記録する流れを保つ。

## 個人ルートと選択

各編の6人×5話×2ルートでは、三人からの同時の誘い、二人きりへ別の相手が来る場面、甘い嫉妬、からかい、人前での好意や次の約束を扱う。趣味の共同作業だけで進めず、主人公へ向けた具体的な台詞と行動を各人物の性格で描く。

締めの選択には、それぞれ別の反応・表情・次の展開の予告を持たせる。選んだ後の結果が常に同じ笑顔や同じ予告へ戻らないようにする。身体的に近づく選択は、選択文で何をするかを示す。日本語の恋愛の選択とThaiの正誤を分け、語学の高得点を親密さの条件にしない。

## 前の選択を引き継ぐ

既存の会話活動の保存版 `1` に、エピソードごとの任意項目 `lastStory: { routeId, choiceId }` を追加する。明示的な終了操作で、直近の物語選択の登録IDだけを保持する。物語本文・自由入力・音声は保存しない。以前の記録にこの項目がなくても読み込め、過去の選択を推測して埋めない。

次の話には「前の選択の続き」を表示し、パスポートの直近記録からも選んだ行動と予告を参照できる。5話の後日談も、記録された最終選択の反応へつなげる。既存の好感度、日次、前提、学習成績の計算を変更せず、街と学園の保存先を分けたまま扱う。

## 教材と実装

群像の会話・個人ルートの物語は日本語のフィクションで、36表情を使う。語学活動も [ROMANCE_DIALOGUE.md](ROMANCE_DIALOGUE.md) の15ターンを用い、相手へ好意や次の約束を返す。追加語句IPAの照合と全文の監修を区別し、5段階の会話練習、語句の組立、想起、有限の言い直しを保つ。新しい音声素材・外部APIは追加しない。夜の画像は [ROMANCE_ART.md](ROMANCE_ART.md) に記録する。

- `romance-ensemble.ts` と `RomanceEnsemble`：三人の誘い・反応、グループの掛け合い、解放済みエピソードへの入口。
- 人物別の街・キャンパス物語データ：他の相手も登場するルートと、選択別の反応・予告。
- `JourneyWrapChoice.nextHook`：締めの選択に対応する予告。
- `romance-journey.ts` の物語記憶：任意の登録IDの検証、前話の続き・最終話の後日談。

実行した検証と未確認の範囲は [VALIDATION.md](VALIDATION.md) に記録する。
