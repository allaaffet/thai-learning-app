# はじめから会話を使うカリキュラム

## 方針

文字・発音の理解と、短いやり取りを使う体験を最初のミッションから並行させる。文字を全て覚え終えるまで会話を待たせず、「挨拶してみる→音や文字に気づく→もう一度返す」という流れにする。会話を別画面の任意機能として置くだけでなく、全30課の本編に会話ゴールを持たせる。

Thai・IPA・訳・選択肢は、既存の4シーン・12ステップと34語句のカタログを再利用する。新しい例文、全文IPA、録音素材は生成しない。全体は引き続き専門家監修前の教材案である。

## 最初の6課

| 本編のLesson ID | 会話で使うこと | 文字・発音との関係 |
| --- | --- | --- |
| `sounds-and-letters` | こんにちは、と挨拶を返す | まず表現を聞き、文字と音が結び付くことを知る |
| `first-consonants` | 受けてもらったお願いに、お礼を言う | 短い表現をまとまりとして使いながら基本子音を学ぶ |
| `breath-and-sounds` | 水を丁寧に頼む | 伝えたいことを先に持ち、有気・無気の説明へつなぐ |
| `vowel-length` | お礼に、どういたしましてと返す | やり取りを続けつつ、母音の長短を整理する |
| `syllable-endings` | 日本から来たと伝える | 表現の使い方を体験し、音節末の説明も学ぶ |
| `five-tones` | 挨拶・出身・お礼への返答をつなぐ | 既習の表現を再使用し、音と文字の基礎を振り返る |

会話表現の全ての綴り・声調規則を、その課で解析できるとは扱わない。入門時は意味のあるまとまりとしてモデルを使い、読みの仕組みは既存の前提順で少しずつ理解する。

後続の課では依頼・断り、値段・買う意思、場所・方向を段階的に増やし、既習シーンを繰り返す。現カタログにはアスペクト・比較・接続を扱う会話はないため、対応する文法課でも会話カードは既習のやり取りの復習とし、その新しい文法を会話で練習済みと表示しない。

## 本編の流れ

1. ミッションの初めに場面、日本語の目標、相手と返答のお手本を示す。未知のThaiだけを見せて返答を当てさせない。
2. 1〜3ステップの短いやり取りで返答を選ぶ。複数の登録済みの丁寧表現を受け付け、選択直後の音声確認と回答確定を分ける。
3. 文字・発音・文法の発見と確認へ進む。全30課で、そのあと確認5問の前に、冒頭で見た返答を登録語句から組み立てる。語句を戻す・並べ直す・ヒント・初回正誤と理由を扱い、既存の説明・例・確認5問は省かない。
4. 少し後で同じ会話を思い出す。お手本や訳のヒントも参照できる。会話で使ったことと、読める仕組みを往復させる。

各ステップは誤答でも理由と受け付ける返答例を確認して先へ進める。正解するまで無限に繰り返させず、後の想起カードでもう一度使う。これはモデル付きの練習であり、自由な会話能力や発音を採点する機能ではない。

ホーム・冒険マップでは会話ゴールを先に示し、元の文字・発音テーマも確認できるようにする。教科書形式のLearnには対応する会話の導入と本編への導線を置き、詳しい解説を読みたい場合にも同じ学習目的を参照できるようにする。

## データ・採点・保存

`src/data/course-conversations.ts` の `CourseConversationUnit` はLesson ID、会話ゴール、場面、所属シーンとステップ、注目する語句のIDを持つ。`MissionCard` の `conversation` は `learn` / `recall` を区別し、`course-dialogue-card.tsx` がモデル・返答・理由を表示する。

- 返答の判定は既存の `gradeConversationChoice` を使い、複数の `answerIds` を保持する。性別を登録させたり、一つの丁寧詞だけを正解にしたりしない。
- 会話カードは確認5問の `core` から分離する。確認5問の初回回答による80%条件、初回だけのXP、合計1210XP、保存キーと版 `1` は変更しない。
- 組込み会話と語句組立の回答・終了は画面内だけで扱う。XP・SRS・クエスト・バッジや、任意会話の終了回数へ追加しない。部分ステップから `recordConversationCompletion` を呼ばない。
- 別画面の `/conversations` は従来どおり4シーン全体を練習し、明示終了時だけ専用領域へ回数・日時を保存する。

## 音声・教材の品質

相手・お手本・選択した返答の音声は、ユーザーが押した同じイベント内で既存のThai TTSへ要求する。表示、次のステップ、お手本や訳の展開で自動再生せず、移動・離脱で停止する。音声がない端末でも日本語訳と表示で続けられる。録音・ASR・マイク要求は新たに追加しない。

語ごとの辞書形IPAは参照できるが、並べて文全体のIPAにしない。会話の出典は所属する `ConversationScenario.sourceIds` と [PHASE5_SOURCES.md](PHASE5_SOURCES.md) の確認範囲を使い、元LessonのUnicode資料が会話を検証したかのように表示しない。辞書形IPAの限定照合と、訳・場面・用法・合成音声の専門家監修を区別する。

SEは各会話ステップの初回確定回答で既存の正誤音を1回だけ使う。選択・モデルの表示・次のステップ・会話終了だけでは追加SEを鳴らさない。既存の初期オフ・音量・教材音声優先を保つ。

語句組立の対応表・判定・画面と、既存の採点対象との分離は [COURSE_WORD_BUILDERS.md](COURSE_WORD_BUILDERS.md) に記録する。実行した検証と未検証事項は [VALIDATION.md](VALIDATION.md) に記録する。
