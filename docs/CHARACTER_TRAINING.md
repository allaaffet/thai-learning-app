# 文字トレーニング

## ねらいと入口

一度に覚える文字を少なくし、大きな字形と字母名の音声を結び付ける短い練習を繰り返す。全44子音を対象とし、母音・筆順・発音採点の新機能は追加しない。

ホームの「文字をゲームで覚える」、メニューの「文字トレーニング」、タイ文字ノートから `/character-practice` へ進む。文字ノートの個別リンクは `?focus=<文字ID>` で選んだ字を練習候補へ含める。未知のIDから文字や教材を生成しない。

## 少ない文字で一回ずつ

1. **選ぶ**：全44字から2〜8字を選ぶ。最初は ก・ม・น・ง の4字。基本セットと ก・ถ・ภ、ข・ช・ซ、บ・ป・ผ・ฝ の見比べセットも用意する。ฃ・ฅ は通常使わない字と表示し、初期セットに含めない。
2. **覚える**：大きな字形を見て、字母名と例語の音声をボタンから確かめる。絵の手がかりは使わない。字母名の最初の音節のIPAを補足に出す場合は、字母名全体の発音と混同しないラベルを付ける。慣れたら確認を飛ばしてチャレンジへ進める。
3. **8問チャレンジ**：「聞こえた名前の文字は？」で字母名の音声を再生し、聞き終えてから字形を選ぶ。「答えを確認」で確定すると正誤と理由を表示し、名前を聞き直せる。「わからない」も音声を聞き終えてから使う。確定後の選び直しで記録を変更しない。
4. **見直す**：8問の結果から間違えた文字をもう一度練習する。間違えた字が1字なら見比べる1字を添え、両方を苦手と表示しない。再練習も8問とする。

色だけで正誤を伝えず、文字とアイコンを使う。ハート、失敗による停止、XP減算、ランキングを設けない。短い正解表示や終了音は、効果音なしでも理解できる画面を補う。

## 出題と同音の扱い

保存データがない場合は、字母名の音声から字形を選ぶ `audio-to-letter` で始める。保存済みの選択文字・形式は維持する。従来の3形式は「文字だけで練習」から任意に選べる。

| モード                            | 出題                                 | 境界                                                       |
| --------------------------------- | ------------------------------------ | ---------------------------------------------------------- |
| 音声から文字（`audio-to-letter`） | 完全な字母名の音声を聞いて字形を選ぶ | 初頭音だけの聞き分け・発音の採点ではない                   |
| 名前から文字                      | 日本語の名前の手がかりから字形を選ぶ | 問題文に正解の字形・字母名を先に見せない                   |
| 文字から初頭音                    | 大きな字形から基本の初頭音IPAを選ぶ  | 聞き取り・録音・発音の評価ではない                         |
| ミックス                          | 従来の文字だけの2形式を組み合わせる  | 初頭音形式を作れないセットでは名前形式へ切り替えると伝える |

音声問題は既存の `name` にある完全な字母名（例：`ก ไก่`）を読み上げる。初頭音を共有する字も字母名では区別できるため、初頭音だけの音声から同音の字を一つだけ正解にする問題とは区別する。全44字の字母名は異なる文字列であることを検査するが、端末TTSが各字を自然で正確に読むと保証しない。

音声問題の採点と「わからない」は、その問題の再生が正常に終了し、再生中でない場合に限る。再生エラー・取消し・音声未対応を「聞いた」と扱わない。再び再生を始めたら、聞き終えた状態を解除し、次の問題でも聞き直しを必要にする。音声を使えない場合は理由と「文字だけで練習」への切替を示す。切替では未終了の回を取り消して設定へ戻し、音声を聞かずに音声問題を採点・保存しない。

文字だけの初頭音形式では、同じ初頭音の文字を一つだけ正解にする問題は作らない。初頭音の選択肢は同一IPAをまとめ、対象字に有効な別音も誤答候補から外す。特に ฑ の `/d/` は有効な別音として扱う。対象のどれかに適切な誤答候補がなければ、そのセットの「文字から初頭音」を使えなくし、ミックスは名前形式だけにする。この制限は完全な字母名を聞く音声形式には適用しない。

問題の対象と候補は選択した文字の範囲から作る。出題順はseedから再現できる純粋なロジックとし、未知の語や字形の分析から発音・声調を推測しない。日本語の手がかりは既存の `meaning` から文字識別用の末尾だけを除き、Thai・IPA・結合文字を分解・正規化しない。

## 教材・字体・音声

教材は `src/data/alphabet.ts` の字形、字母名、初頭音、語義、注記、出典、確認状況を再利用する。全44字の言語情報は `unreviewed`。Unicode資料との照合は文字の識別・名前などに限り、IPA・語義・用例の専門家監修とは表示しない。新しい単語・音声ファイル・筆順・字形の由来を生成しない。

標準のループあり／ループなし字体を共通スイッチで切り替えられ、文字列と採点は変えない。既存のWeb Speech APIによる端末のタイ語合成音声を使い、字母名・例語を利用者のボタン操作で再生する。未監修の合成音声であること、提供元へ通信する場合があることを操作前に伝える。タイ語の声がない場合は理由を示し、他言語で代用しない。入場時の自動再生、マイク・音声認識、新しい録音素材、APIキーや有料サービスを追加しない。

効果音は共通設定に従い、初期オフ・音量35%。最初の確定回答で既存の `correct` / `incorrect`、8問終了の操作で `review-complete` を要求する。TTSなどが音声を使う間は既存のaudio focusで抑止する。詳しくは [SOUND_EFFECTS.md](SOUND_EFFECTS.md) を参照する。

## 保存するもの

文字練習だけの `localStorage` キー `thai-learning.character-training.v1` を使う。

| 項目                  | 内容                                                       |
| --------------------- | ---------------------------------------------------------- |
| `version`             | `1`                                                        |
| `selectedIds`・`mode` | 次回に使う2〜8字と出題形式                                 |
| `records`             | 文字IDごとの正解・誤答回数、最後に練習した日時、直近の正誤 |
| `sessionsCompleted`   | 終了した8問の回数                                          |
| `recentSessionIds`    | 重複反映を防ぐ直近100回のID                                |
| `lastPracticedAt`     | 最後に8問を終えた日時                                      |

保存版は `1` のまま、形式に `audio-to-letter` を加える。旧3形式の設定と文字別記録は引き継ぎ、音声形式へ自動変更しない。設定は開始操作で、文字別の結果は8問を終えた時点で保存する。未終了の問題・回答は画面内だけで、再読み込みすると失われる。同じセッションIDの結果を再処理しても回数を増やさない。直近100回より古いIDは保持しない。

既知の文字ID、2〜8字の重複のない選択、形式、整数の回数、日時、記録間の整合性を検証する。不正JSON・未知版の原文は自動上書きせず、保存をやり直す明示操作まで保護する。保存できない場合も通知し、このタブのメモリで続ける。読込みだけで初期値を書き込まない。他タブの通常更新は保存前の再読込みと変更通知で取り込むが、厳密に同時の書込みと別端末の同期は保証しない。

文字別の直近誤答は再練習候補であり、習熟度の測定ではない。受講の `thai-learning.progress.v1` とSRSの `thai-learning.review.v1` を変更せず、XP、前提レッスンの解放、SRS予定、日次クエスト、バッジ、受講の学習日へ加算しない。

## 実装と検証の境界

- `src/data/character-training.ts`：セットと日本語の名前の手がかり。
- `src/lib/character-trainer.ts`：モード、選択検証、出題、最初の回答の採点。
- `src/lib/character-training-progress.ts`：文字別記録、重複防止、保存検証・読書き。
- `src/components/use-character-training.ts`：hydration後の復元、保存通知、タブ内の継続。
- `src/components/character-training.tsx`：選択・確認・8問・結果の画面。
- `src/components/character-audio-prompt.tsx`：既存の `useThaiSpeech` を使う字母名再生と、正常終了に限る回答解放。

ユニットテストでは全44字の参照・異なる字母名、選択制限、seed、対象の偏り、同音・別音の誤答除外、採点、新旧4形式の保存検証・復元・破損原文保護・重複防止を扱う。Playwrightでは模擬TTSの再生成功・再生中・再再生・取消し・エラー・非対応での回答可否、文字だけへの明示切替、学習から8問終了と再読み込み、誤答・スキップ・再練習、保存不可、旧進捗への非干渉、PC・モバイルの操作を確認する。実際の実行結果と件数は [VALIDATION.md](VALIDATION.md) に記録し、言語教材の監修完了やMac・Safari実機での音声品質を自動テストの成功から保証しない。
