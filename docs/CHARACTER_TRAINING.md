# 文字トレーニング

## ねらいと入口

一度に覚える文字を少なくし、字母名の音声・読み方の表示から字形を選ぶ短い練習を繰り返す。全44子音を対象とし、母音・筆順・発音採点の新機能は追加しない。

ホームの「文字をゲームで覚える」、メニューの「文字トレーニング」、タイ文字ノートから `/character-practice` へ進む。文字ノートの個別リンクは `?focus=<文字ID>` で選んだ字を練習候補へ含める。未知のIDから文字や教材を生成しない。

## 少ない文字で一回ずつ

1. **選ぶ**：全44字から2〜8字を選ぶ。最初は ก・ม・น・ง の4字。基本セットと ก・ถ・ภ、ข・ช・ซ、บ・ป・ผ・ฝ の見比べセットも用意する。ฃ・ฅ は通常使わない字と表示し、初期セットに含めない。
2. **覚える**：大きな字形を見て、確認する文字をタップすると字母名が流れる。再生ボタンから字母名や例語を聞き直せる。最初の表示では再生しない。絵の手がかりは使わない。字母名の最初の音節のIPAを補足に出す場合は、字母名全体の発音と混同しないラベルを付ける。慣れたら確認を飛ばしてチャレンジへ進める。
3. **8問チャレンジ**：「音声から文字」は字母名を聞き終えてから、「読み方から文字」はIPAと字母名の英字表記を見て、字形を選ぶ。日本語の意味や絵から当てる問題は使わない。「答えを確認」で確定すると正誤と理由を表示し、名前を聞き直せる。確定後の選び直しで記録を変更しない。
4. **見直す**：8問の結果から間違えた文字をもう一度練習する。間違えた字が1字なら見比べる1字を添え、両方を苦手と表示しない。再練習も8問とする。

色だけで正誤を伝えず、文字とアイコンを使う。ハート、失敗による停止、XP減算、ランキングを設けない。短い正解表示や終了音は、効果音なしでも理解できる画面を補う。

## 組み合わせを変える

固定セットは19種類。最初の5セットのID・名前・文字を維持し、子音クラス、似た形、同じ基本初頭音の組を追加する。現用42字が少なくとも1組に含まれ、廃用2字は「廃用字も確認」の専用セットに限定する。最初の5組に続く14組は追加セット一覧から開ける。

「新しい組み合わせ」では、現用42字から4字・8字を選ぶ。選び方は全体・未練習を多め・直近のまちがいを多めの3つ。未練習は終了した8問の記録がない文字、直近誤答は文字別記録の `lastCorrect === false` を対象にする。過去に一度誤答しただけで、最後は正解の文字を苦手と決め付けない。

候補が足りないときは他の現用字を補い、実際に含めた対象数と補完数を表示する。前回と同じ集合になった場合は1字を交換し、順序だけを変えた同じ組を続けない。提案はseedから再現できる純粋な処理で、字形・IPA・字母名を生成・変更しない。

追加セットの選択・おまかせの生成は画面内の下書きだけで保存しない。従来の確認学習・8問の開始時だけ選択設定を保存し、ペアさがしからは書き込まない。4字・8字のおまかせとは別に、既存の2〜8字の自由選択も使える。

## ペアさがしで遊ぶ

選んだ2〜8文字を使う、点数・保存なしのウォームアップ。「ペアさがしで遊ぶ」から、音声・読み方カードとタイ文字を組み合わせる。従来の「このセットで覚える」と8問への直接開始も残す。

手がかりカードを選び、対応する字形を選ぶ。正しい組合せは固定され、見つけた文字がその回だけのコレクションに並ぶ。間違えた場合は理由をすぐ表示し、減点・ハート・制限時間なしで試し直せる。各周で選んだ全文字を1回ずつ組み合わせ、1周目を終えたら「シャッフルしてもう1周」でカードと文字を独立に並べ替える。2周目の終了は「2周クリア！」と表示する。2文字なら合計4ペア、8文字なら16ペアで、8問を解いたようには表示しない。

音声形式では、音声カードを1回押すと、その操作内で完全な字母名を再生する。同じカードを押すと聞き直し、別のカードを押すと前の音声を止めて切り替える。聞き直すたびに回答待ちへ戻り、そのカードの音声が正常終了して再生中でない場合だけ、対応する文字を選べる。再生・停止ボタンも残す。周の変更、戻る操作・画面離脱では古い再生・完了通知を取り消す。ページ表示・周の開始・音声が後から利用可能になっただけでは再生せず、操作を予約して後から鳴らすこともしない。再生失敗・タイ語の声がない場合は理由と「読み方でペアさがし」を示し、同じ文字セットで読み方形式の1周目から始め直せる。

スマートフォンの音声形式では、音声カードを上、タイ文字を下に並べて操作しやすくする。PCの音声形式と読み方形式は、手がかりカードと文字を横に並べる。文字コレクションは文字拡大時にも折り返して表示する。

読み方形式は「字母名の最初の音節」のIPAと「字母名の英字表記（Unicode名）」を必ず一緒に示し、同じ最初の音節の字も区別できるようにする。日本語の意味・絵の手がかりは使わない。選んだ字の任意の音声ボタンは折りたたまずに表示し、1回で聞ける。読み方カードを選ぶだけでは再生しない。音声・IPA・Unicode名の確認状況は下記と同じ。

ペアさがしのコレクションと2周の進行は画面内だけの一時状態で、設定・文字別記録・XP・バッジ・SRS・クエストを保存・更新しない。文字に繰り返し触れた記録であり、習熟度・100%の正答率や検証済みの定着を示さない。終えたら任意の「8問で確かめる」から既存のクイズへ進める。読み方へ切り替えて遊んだ場合は、その実際の形式をクイズへ引き継ぐ。記録するのは通常どおり8問を終えた結果だけ。

正解・誤答の試行には既存の効果音設定を使い、2周終了後の明示的な完了・クイズへの移動操作だけに終了音を付ける。最後のペアがそろった表示や入場をきっかけに終了音を自動再生しない。カードの短い強調は動きを減らす設定で止め、無音でも固定済みのペア・理由・進み具合を読み取れるようにする。

## 出題と同音の扱い

保存データがない場合は「音声から文字」で始める。選べる形式は次の2つで、どちらも音声・読み方から字形を選ぶ。日本語の名詞や意味を出題の手がかりにしない。

| モード                             | 出題                                                       | 境界                                                   |
| ---------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------ |
| 音声から文字（`audio-to-letter`）  | 完全な字母名の音声を聞いて字形を選ぶ                       | 正常な再生終了後に回答・スキップできる                 |
| 読み方から文字（`name-to-letter`） | 字母名の最初の音節のIPAとUnicode名の英字表記から字形を選ぶ | 表示だけでも答えられ、任意の音声再生は回答条件にしない |

音声問題は既存の `name` にある完全な字母名（例：`ก ไก่`）を読み上げる。初頭音を共有する字も字母名では区別できるため、初頭音だけの音声から同音の字を一つだけ正解にする問題とは区別する。全44字の字母名は異なる文字列であることを検査するが、端末TTSが各字を自然で正確に読むと保証しない。

音声問題の採点と「わからない」は、その問題の再生が正常に終了し、再生中でない場合に限る。再生エラー・取消し・音声未対応を「聞いた」と扱わない。再び再生を始めたら、聞き終えた状態を解除し、次の問題でも聞き直しを必要にする。音声を使えない場合は理由と「読み方から文字」への切替を示す。切替では未終了の回を取り消して設定へ戻し、音声を聞かずに音声問題を採点・保存しない。

読み方の問題には、既存の `ipa` を「字母名の最初の音節」として表示し、`unicodeName` の `THAI CHARACTER ` を除いて小文字にした文字列（例：`ngo ngu`）を「字母名の英字表記（Unicode名）」として添える。同じ最初の音節を持つ字も、字母名全体の英字表記を使って区別する。Unicode名は文字識別用の表記であり、正確な発音転写ではない。字母名全体のIPAや新しいカタカナ発音を生成しない。完全な字母名を聞く任意のボタンは折りたたまずに表示する。表示から答える形式なので再生完了を採点条件にしない。

問題の対象と候補は選択した文字の範囲から作る。出題順はseedから再現できる純粋なロジックとし、未知の語や字形の分析から発音・声調を推測しない。日本語の名前の手がかりを返す `getCharacterTrainingCue` は確認カード・解答後・情報表示だけに使い、音声・読み方の問題文には出さない。Thai・IPA・結合文字は分解・正規化しない。

以前の `mixed` / `letter-to-sound` は保存データと内部ロジックの互換性のため引き続き受け付けるが、画面の選択肢には出さない。読み込み時は画面内で「読み方から文字」へ読み替え、保存されていた文字別記録を引き継ぐ。読込みだけで形式を書き換えず、次に利用者が従来の確認学習・8問を開始したときに選択中の形式を保存する。

## 教材・字体・音声

教材は `src/data/alphabet.ts` の字形、字母名、初頭音、語義、注記、出典、確認状況を再利用する。全44字の言語情報は `unreviewed`。Unicode資料との照合は文字の識別・名前などに限り、IPA・語義・用例の専門家監修とは表示しない。新しい単語・音声ファイル・筆順・字形の由来を生成しない。

標準のループあり／ループなし字体を共通スイッチで切り替えられ、文字列と採点は変えない。既存のWeb Speech APIによる端末のタイ語合成音声を使い、字母名・例語を、音声カードや文字タブの押下・再生ボタンの明示操作で再生する。未監修の合成音声であること、提供元へ通信する場合があることを操作前に伝える。タイ語の声がない場合は理由を示し、他言語で代用しない。入場時の自動再生、マイク・音声認識、新しい録音素材、APIキーや有料サービスを追加しない。

効果音は共通設定に従い、初期オフ・音量35%。8問の最初の確定回答とペアさがしの各試行で既存の `correct` / `incorrect`、8問終了とペア2周終了後の明示的な完了・クイズへの移動操作で `review-complete` を要求する。TTSなどが音声を使う間は既存のaudio focusで抑止する。詳しくは [SOUND_EFFECTS.md](SOUND_EFFECTS.md) を参照する。

## 保存するもの

文字練習だけの `localStorage` キー `thai-learning.character-training.v1` を使う。

| 項目                  | 内容                                                       |
| --------------------- | ---------------------------------------------------------- |
| `version`             | `1`                                                        |
| `selectedIds`・`mode` | 次回に使う2〜8字と出題形式                                 |
| `records`             | 文字IDごとの正解・誤答回数、最後に練習した日時、直近の正誤 |
| `sessionsCompleted`   | 終了した8問の回数                                          |
| `recentSessionIds`    | 重複反映を防ぐ直近100回のID                                |
| `lastPracticedAt`     | 最後に8問を終えた日時                                      |

保存キーと版 `1` は維持する。`name-to-letter` は表示上「読み方から文字」として使い、以前の `mixed` / `letter-to-sound` は画面内だけでこの形式へ読み替える。元の文字別記録は初期化しない。設定は従来の確認学習・8問の開始操作で、文字別の結果は8問を終えた時点で保存する。ペアさがしの開始・正誤・周の変更・終了では設定も結果も保存しない。未終了の問題・回答は画面内だけで、再読み込みすると失われる。同じセッションIDの結果を再処理しても回数を増やさない。直近100回より古いIDは保持しない。

既知の文字ID、2〜8字の重複のない選択、形式、整数の回数、日時、記録間の整合性を検証する。不正JSON・未知版の原文は自動上書きせず、保存をやり直す明示操作まで保護する。保存できない場合も通知し、このタブのメモリで続ける。読込みだけで初期値を書き込まない。他タブの通常更新は保存前の再読込みと変更通知で取り込むが、厳密に同時の書込みと別端末の同期は保証しない。

文字別の直近誤答は再練習候補であり、習熟度の測定ではない。受講の `thai-learning.progress.v1` とSRSの `thai-learning.review.v1` を変更せず、XP、前提レッスンの解放、SRS予定、日次クエスト、バッジ、受講の学習日へ加算しない。

## 実装と検証の境界

- `src/data/character-training.ts`：セット、読み方に使う表示、日本語の名前の補足。
- `src/lib/character-selection.ts`：現用字のおまかせ選択、未練習・直近誤答の優先、集合の連続重複回避。保存・音声・時計から独立する。
- `src/lib/character-trainer.ts`：モード、選択検証、出題、最初の回答の採点。
- `src/lib/character-pairs.ts`：ペア盤面の作成・カードと文字の並べ替え・組合せ判定。保存処理から独立した純粋なロジック。
- `src/lib/character-training-progress.ts`：文字別記録、重複防止、保存検証・読書き。
- `src/components/use-character-training.ts`：hydration後の復元、保存通知、タブ内の継続。
- `src/components/character-training.tsx`：選択・確認・8問・結果の画面。
- `src/components/character-audio-prompt.tsx`：既存の `useThaiSpeech` を使う字母名再生と、正常終了に限る回答解放。

固定19組の現用字の網羅・廃用字の明示、従来5組の互換性、おまかせの4字・8字、seed再現、優先対象・補完数、連続した集合の変更、保存前の下書きも検証対象にする。

ユニットテストでは全44字の参照・異なる字母名、選択制限、seed、対象の偏り、表示する2形式、問題文に日本語の意味を出さないこと、Unicode名と最初の音節IPAの区別、旧形式との互換性、採点、保存検証・復元・破損原文保護・重複防止を扱う。Playwrightでは模擬TTSの再生成功・再生中・再再生・取消し・エラー・非対応での回答可否、読み方形式への明示切替、表示だけでの回答、旧形式の画面内読み替えと開始前の原文保持、学習から8問終了と再読み込み、誤答・スキップ・再練習、保存不可、旧進捗への非干渉、PC・モバイルの操作を確認する。音声カードの1操作での開始・同じカードの聞き直し・準備完了だけでは鳴らないことも対象にする。ペアさがしは各周の全対象、カードと文字の独立した並べ替え、正誤と再試行、2周の件数、音声の対象変更・取消し・遅延通知、読み方への切替とクイズへの引継ぎ、保存への非干渉を確認する。実際の実行結果と件数は [VALIDATION.md](VALIDATION.md) に記録し、言語教材の監修完了やMac・Safari実機での音声品質を自動テストの成功から保証しない。
