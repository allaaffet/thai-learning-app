第1〜3章の旧14レコード・70解答・570XPを引き継ぎ、追加8レッスンの40問をPC・スマートフォンで実回答しました。全22完了・110解答・890XP、旧記録の無破壊、再読み込み後の復元、URLによる前提の迂回防止を確認しました。既存の字体切替・書取りを含む全E2E48件が成功しました（失敗・スキップなし）。

- 子音クラス・生死・母音長・声調記号の基本対応、先行子音と真正子音連続、`โต๊ะ` の中子音＋死音節＋ไม้ตรี、対応外条件をユニットテストで検証。
- 32語の解析・IPA・期待声調・出典を検査し、未知語・不正入力・分析と登録声調の不整合・未確認の辞書補完は推測せず停止。不整合時の説明にも却下した声調の結論を残さない。
- 登録語の検索、初頭／母音／末子音字の分解、5声調の模式図、手動条件変更、字体切替と320px表示。図は録音の実測グラフではない。

## 開発依存の既知事項

開発依存を含む `npm audit --audit-level=high` では、Lint用の `eslint-config-next → @next/eslint-plugin-next → fast-glob → micromatch → braces` に関するhigh報告が5件残っています。根本の報告は [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)（深く入れ子にしたパターンによるスタック枯渇）です。このアプリの本番依存には含まれません。

確認時点で監査が提示する自動修正はNext.js用Lint設定のメジャー版を戻す変更でした。互換性を壊す強制修正は行わず、互換性のあるLint依存を固定しています。ESLint 9の非推奨通知も残るため、対応するプラグインの更新後にLint依存を更新し、再検証してください。署名・チェックサム・TLS検証を無効にした回避は使用していません。
