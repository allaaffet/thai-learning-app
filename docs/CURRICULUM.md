# タイ語学習カリキュラム

## 教育方針

文字・音・意味を同時に少しずつ扱います。日本語のカナを発音の基準にせず、IPA と声調記号を統一して使用します。長母音は `ː`、有気音は `ʰ`、声調は Chao の五度式声調文字で示します（例：`/kaː˧/`）。`˧` は中平、`˨˩` は低、`˥˩` は下降、`˦˥` は高、`˩˩˦` は上昇の概略です。記号は音声そのものではなく、実際の音高には話者・文脈による差があります。

各レッスンは Learn → Explore → Practice → Review の4段階、8〜12分を想定します。Practice は解説つきの選択問題と文字識別問題です。初回の合格（80%以上）で完了を記録し、次のレッスンへ進みます。XP は学習の活動記録であり、習熟度そのものではありません。

### Learn — 理解する

各レッスンは目標、短い解説、単語・音節の例、日本語との違いを持ちます。子音字の名前（例：ก ไก่）と、単語の初頭での音（/k/）を区別します。

### Explore — 確認する

タイ文字・IPA・意味を同時に見て比較します。音声素材が未提供のため、音声ボタンや「聞き分け」の採点は提供しません。声調の音節表には意味を割り当てず、綴りの比較用であることを示します。書き順・書き取りも Phase 1 では提供しません。

### Practice — 練習する

文字識別、発音情報の対応、長短・位置・音節構造・声調の概念理解を問います。全問題に正答の根拠を用意し、誤答を責めずに解説へ戻れる構成にします。音声なしで音の弁別能力を評価したとは表示しません。

### Review — 定着させる

要点と解答結果を確認します。合格条件を満たして完了すると進捗とXPを保存します。同じレッスンを完了し直してXPを重複獲得することはありません。未合格の場合は学習をやり直せます。

## 誤解を防ぐ範囲設定

- 第1章の文字は10子音だけです。子音44文字の網羅や書き順の提示は行いません。
- 母音の短音・長音は意味を区別しますが、声調や末子音など他の条件も影響します。無条件の「この字ならこの声調」という規則を作りません。
- 短母音の無末子音音節で現れる声門閉鎖音には導入だけ触れ、全ての短母音を完全な最小対にしていません。
- `-` は母音パターンの子音位置を示す図示用記号です。タイ語の単語の一部ではありません。
- /ŋ/ は日本語の「ン」で代用しきれません。/r/ も日本語のラ行と同一ではありません。
- 末子音の ก は /k̚/。後ろに日本語の「ク」の母音を足さず、破裂を解放しません。
- 5声調の例は中子音 ก と長母音 า に限定します。声調記号だけから全ての語の声調を判定することはできません。
- 子音クラス・母音長・末子音・声調記号などを組み合わせる一般判定エンジンは未実装です。

## 教材の検証と出典

教材データには `sourceIds` と `verification` を保持します。`source-checked` は指定した資料との限定的な照合、`unreviewed` は未照合・専門家レビュー前を意味します。いずれも専門家による監修完了の意味ではありません。各レッスンは日本語の独自説明として作成し、出典の本文や音声を転載しません。出典候補、接続結果、確認できた範囲は [CONTENT_SOURCES.md](CONTENT_SOURCES.md) に記録します。

公開前にはタイ語教育の専門家による、IPA・声調・用例の自然さ・日本語説明のレビューを必要とします。現段階の画面には「教材案・専門家レビュー前」を表示します。
