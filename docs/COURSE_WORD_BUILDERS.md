# 本編の会話を組み立てる練習

## 学習のねらい

全30課の本編ミッションに、会話で見た返答を登録語句から組み立て直すカードを1枚ずつ設ける。会話のお手本と文字・発音・文法の解説を見たあと、確認5問の直前で取り組む。選択式で返した表現を、少し間を空けて自分で並べる練習につなげる。

| 本編の最初の課 | 組み立てる内容 |
| --- | --- |
| `sounds-and-letters` | 挨拶を返す |
| `first-consonants` | お礼を伝える |
| `breath-and-sounds` | 水を頼む |
| `vowel-length` | お礼に応じる |
| `syllable-endings`・`five-tones` | 日本から来たことを伝える |

後続の課でも、各課の `CourseConversationUnit` 内で提示済みの返答を使う。後半のアスペクト・比較などに未対応の会話は既習表現の復習であり、その新しい文法の会話練習を済ませたとは表示しない。

## 操作と判定

語句を押して返答へ並べ、選んだ語句を戻す、全体を並べ直す、お手本を開く操作を用意する。タッチとキーボードで使え、ドラッグ操作を必須にしない。語句を選ぶ同じ操作内で、その登録語句の端末TTSを要求する。

初回の確定回答だけを判定し、正誤と理由を表示する。誤答でも正答例を確認して次のカードへ進める。同じ問題を無限にやり直させず、確定後の選び直しで初回結果を変更しない。登録済みの複数の丁寧な返答を受け付け、語句IDの順・不足・余分な語句・重複数を確認する。

Thaiの文字列を推測分割せず、既存の4会話シーン・12ステップ・34語句の `wordIds` を使う。Unicodeの正規化、結合記号の並べ替え、新しいThai・全文IPAの生成は行わない。確認状況と出典は元の会話から引き継ぎ、教材・訳・端末合成音声は専門家監修前と示す。

## 成績・音声・保存

この `word-builder` カードは画面内の練習であり、既存の確認5問の `core` と分離する。組み立てた回数は別に表示し、正誤・ヒント・語句列を `ExerciseAttempt`、XP、SRS、クエスト、独立会話の終了記録へ送らない。全30課・150問・初回1210XP、確認5問の80%条件、保存キーと版 `1` を維持する。第6・7章にある採点対象の語順問題とは別の活動である。

SEは初回の確定操作にだけ既存の正解・誤答音を1回要求する。語句選択、ヒント、表示、次のカードでは追加SEを鳴らさない。TTSは表示・次のカード・音声準備完了で自動再生せず、移動・離脱で止める。音声が使えなくても表示で続けられ、マイク・録音・ASRを開始しない。

## 実装

- `src/data/course-word-builders.ts`：全30課と、各課の会話内で使うステップIDの明示的な対応。
- `src/lib/course-word-builder.ts`：既存教材からの語句バンク生成、安定した並べ替え、複数正答の判定。
- `src/lib/course-mission.ts`：モデル・解説の後、確認5問の前に1枚を配置。
- `src/components/course-word-builder-card.tsx` と `src/app/course-word-builder.css`：操作・音声・理由・出典の表示。
- `course-mission-player.tsx`：初回確定後の有限の進行と、保存対象からの分離。

教材対応、モデル先行、男女両方の登録正答、順列・重複、初回結果と成績の分離、音声操作、キーボード・狭い画面を検証する。実行した結果と未確認の範囲は [VALIDATION.md](VALIDATION.md) に記録する。
