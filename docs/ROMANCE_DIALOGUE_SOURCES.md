## 採用予定15ターンへの助言

1. 出会い `สวัสดี`、`คุยด้วยได้ไหม`→`ได้`、`ดีใจที่ได้เจอคุณ`。初めは挨拶、話しかける許可、会えてうれしい気持ち。
2. 隣席 `นั่งด้วยได้ไหม`→`ได้`、`อยากคุยกับคุณ`、`ไปด้วยกันไหม`→`ไปด้วยกัน`。一緒に話したい・行きたいという場面。
3. 好意 `คุณน่ารัก`→`ขอบคุณ`、`คุณชอบใคร`→`ชอบคุณ`、`คิดถึงคุณ`。好意を返す役の練習で、利用者自身の感情を正誤判定しない。
4. デート `พรุ่งนี้ว่างไหม`→`ว่าง`、`ไปด้วยกันไหม`→`อยากไปกับคุณ`、`เจอกันพรุ่งนี้`。明日空いているか、二人で行くか、再会の約束へ。
5. 別れ際 `อยากเจอคุณอีก`、`พรุ่งนี้เจอกันไหม`→`เจอกันพรุ่งนี้`、`ฝันดี`。最後は夜の別れや就寝前メッセージに置く。
- 同文で返す `ดีใจที่ได้เจอคุณ` / `คิดถึงคุณ` は「あなたに会えてうれしい」/「あなたが恋しい」など。`เหมือนกัน`がないのに語句の直訳として「私も」を断定しない。文脈上お互いの気持ちを返すことは可能。
- `ไปด้วยกัน` は「一緒に行く/一緒に行こう」。誘いへの応答として使う台本の役・伝えたいことを明示する。
- `ฝันดี` は「よい夢を／おやすみ」。日中の退出のあいさつ全般へ広げず、夜の別れや就寝前のメッセージにつなぐ。
- 女性の疑問の例は `...คะ`、平叙・応答は `...ค่ะ`、男性モデルは `...ครับ`。このモデルの範囲の説明にし、性別だけで学習者の登録正答を狭めない。
- フォーマル寄りで初心者に識別しやすい `คุณ` を用い、物語の成人同士が好意を伝える会話として扱う。`ชอบ`の恋愛的な解釈は文脈に依存する。
- 単語/語句のIPAを全文へ連結して全文発音の正解にはしない。文・日本語訳・自然さ・文化的な適切さ・端末TTS品質は未監修のまま。
