# Phase 5 第1段階：会話ミッション

## 目的と今回の範囲

ユーザーの「次のフェーズへ」の依頼に基づき、Phase 5を短い場面会話から始める。挨拶、カフェ、買い物、道案内の4シーンで、それぞれ3回のやりとりを練習する。登録や外部APIは不要で、既存の30レッスン・150問・初回合計1210XPは維持する。

これは台本と選択肢を持つガイド付き練習である。自由なAI会話、発音・声調の自動採点、認証、クラウド同期、PWA・オフライン対応、公開環境へのデプロイは今回の実装範囲に含めない。Phase 5全体の完成とは表示しない。

## 学習の流れ

メニュー・ホームから `/conversations` の「会話ミッション」へ進む。シーンの目的と所要時間、練習済みかどうかをカードで確認し、好きなシーンから始められる。既存コースのXPによる解放条件は設けない。

練習では相手のThaiと、その場で伝えたいことを日本語で示す。日本語訳は開いて参照でき、利用できる端末では相手の表現を明示操作で読み上げられる。学習者はThaiの選択肢から返答を選び、「この表現で答える」で確定する。

ねらいに合わない場合は、選んだ表現の意味と理由、ねらいに合う表現をすぐに示し、選び直せる。登録した複数の丁寧表現が同じねらいに合う場合は、どちらも受け付ける。一般に成り立つ別の返答を、単に台本と異なるという理由で不自然・文法的に誤りと断定しない。判定は提示した場面のねらいと選択肢に限る。

3回ともねらいに合う返答を確認すると、その回のやりとりを振り返れる。「この会話の練習を記録」で練習済みとして記録し、再挑戦やシーン一覧へ進める。途中の誤答を含む点数・理解度・発音能力は算出しない。やりとりと選択内容は画面内だけで扱う。

## 教材と音声

- 台本、選択肢、日本語訳、解説は `src/data/conversations.ts` に分離し、全シーンを `unreviewed` の教材案として表示する。
- 語のIPAは実際に参照した辞書資料の照合範囲を記録する。新しい文全体のIPAを語のIPAから連結して生成しない。単語のヒントは文全体の発音転写・自動分かち書きではないと明示する。
- 語の参照IDと並びは教材側で指定し、Thaiの結合文字を分割・正規化しない。翻訳・用法・自然な連続発話の専門家監修が済んだとは表示しない。
- 端末TTSはThaiの明示再生だけに使い、未監修であることと提供元へ通信する場合があることを操作前に示す。タイ語の声がない場合は他言語で代用せず、文字と日本語訳で続けられるようにする。
- 画面・シーン・対象の変更で古い読み上げを取り消し、既存のaudio focusを守る。会話ミッションからマイク・音声認識・録音を開始しない。会話の選択・移動・記録でSEや音声を自動開始しない。

実際の照合範囲と利用条件は [PHASE5_SOURCES.md](PHASE5_SOURCES.md) に記録する。

## 保存と互換性

会話だけの `thai-learning.conversation.v1` に保存版 `1` を持つ。保存するのはシーンごとの終了回数・最終終了日時と、重複反映を防ぐ直近100回のセッションIDだけである。Thai、選択肢、会話履歴、音声、途中の回答は保存しない。

記録時には、実在するシーンの全ステップが元の順序でそろい、それぞれ受け付ける返答であることを保存ロジック側でも確認する。同じセッションの記録を重複加算しない。不正JSON、未知の版・ID・項目、無効な回数や日時は信用せず、明示的な置換操作まで原文を保護する。読込みだけで初期値を書き込まない。

保存が使えない場合は通知し、このタブのメモリで継続する。別の端末への同期や厳密に同時の書込みは保証しない。既存のレッスン・文字・SRS・字体・効果音の保存キーと版を変更せず、会話練習からXP・前提・日次クエスト・バッジ・復習予定を変更しない。「練習済み」は今回のガイド付き練習を終えた記録であり、習熟度の保証ではない。

## 実装の責務

| 層                                         | 主な責務                                                           |
| ------------------------------------------ | ------------------------------------------------------------------ |
| `src/lib/conversation-types.ts`            | シーン、ステップ、返答、語・表現の型                               |
| `src/data/conversations.ts`                | 4シーンの台本、受け付ける返答、語のIPA、出典・確認状況             |
| `src/lib/conversation.ts`                  | 場面に対する返答の判定、全ステップの検証、記録・保存値の検証と保護 |
| `src/components/use-conversations.ts`      | hydration後の復元、明示的な記録、保存失敗時のタブ内継続            |
| `src/components/conversation-practice.tsx` | 一覧、やりとり、即時の理由、再試行、振り返りと記録操作             |

## 確認すること

- 全シーンと単語・出典・関連レッスンの参照、受け付ける丁寧表現、元のThai・IPAの保持。
- 目的に対する返答の判定、誤答理由と再試行、全ステップを終えた回だけの明示記録、二重操作・再読込み。
- 不正・未知の保存値の保護、明示的な置換、保存不可でも継続、既存のXP・SRS・クエストへの非干渉。
- 音声の明示再生・非対応・取消し、画面表示や保存復元で自動再生しないこと。
- PC・スマートフォン、キーボード、字体切替、文字拡大、Thaiの上下記号と横はみ出し。

実行した検証と実端末の確認範囲は [VALIDATION.md](VALIDATION.md) に記録する。
