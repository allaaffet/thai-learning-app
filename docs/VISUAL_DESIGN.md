# 画面デザインと読みやすさ

## 基本方針

まず例・図・数値で概要をつかみ、必要な説明を開いて読める画面にします。ivoryとforest greenの落ち着いた配色を保ち、文章の重複や宣伝文を減らします。教材本文や正答の理由を削ることで表示量を減らす方針ではありません。

## 文字サイズ

| 用途           | 標準サイズ | 共通変数                    |
| -------------- | ---------- | --------------------------- |
| 本文・主な操作 | 16px       | `--text-body: 1rem`         |
| 学習の説明     | 18px       | `--text-learning: 1.125rem` |
| 補足           | 14px       | `--text-small: 0.875rem`    |
| 小さなラベル   | 12px       | `--text-caption: 0.75rem`   |

ブラウザの標準が16pxの場合の目安です。`html` を固定pxにせず、ブラウザの文字サイズ設定を尊重します。見出し・例語のThaiは内容に応じてさらに大きく表示します。タイ文字の上下の記号が切れない行高を取り、狭い画面はカードや操作を折り返して対応します。

## 画面ごとの見方

| 画面         | 最初に見える情報                                      | 必要なときに開く情報                           |
| ------------ | ----------------------------------------------------- | ---------------------------------------------- |
| ホーム       | 次のレッスン、開始ボタン、Thai例のカード、目標・進捗  | 教材の出典・確認状況へのリンク                 |
| ロードマップ | 4段階のアイコン、章の完了数とステップ、レッスンカード | 「この部で学ぶこと」「この章で学ぶこと」       |
| レッスン     | 目標、例語・IPA・意味、最初の概念、注意、対応する図   | 「くわしい説明を読む」                         |
| 単語帳       | カテゴリーアイコン、Thai・主要語のIPA・意味、例文     | 「音節・発音・補足」「関連する学び・出典」     |
| 文法ノート   | 型の順序、例文・意味、語句の役割                      | 「日本語との違い・考え方」「発音・補足を確認」 |
| 学習記録     | 大きい指標値、完了dot、正答率のバー、7日の活動        | 正答率・復習予定・活動の数え方、保存について   |

開閉には標準の `details` / `summary` を使います。本文・例文IPA・注記・出典は元の情報を保持します。クイズの正誤と解答直後の理由は開閉の中へ隠しません。教材の未監修状態と、合成音声が提供元へ通信する可能性は短い表示で常設し、詳しい説明へ進めます。任意の録音・音声認識の扱いも、利用前の説明を維持します。

## 図と数値の意味

- レッスンの音節図は登録済みの語・IPAに一致する教材分析だけを使います。文の役割は既存例文の `segments` から表示します。未登録の綴りやIPAから、音節・声調・文法の役割を推測して補いません。
- 声調の線は教材上の概略を示す模式図です。話者の録音を測定した波形・ピッチではありません。構成要素の図に含まれる `-` は子音の位置で、読み上げる文字ではありません。
- 文法のチップは既存の型の順序を見せます。別の型は区切りを残し、単一の連続する文として扱いません。
- 章のステップ・完了dotはレッスンの完了記録です。XPは学習継続、正答率は解答記録、SRSは自己評価による予定として分けます。
- 7日の棒グラフは終了した受講の解答数です。0問はこのブラウザに記録がない日、読込み中はグラフを表示しない状態です。学習時間・発音の正確さ・語彙習熟度を示しません。

表示の調整は教材データ、前提、採点、XP、進捗・復習の保存仕様を変えません。字体切替、音声、録音、効果音の条件も維持します。

## 確認範囲

PC・スマートフォンの配置、狭い画面と文字拡大、Thaiの上下の記号、開閉のキーボード操作、学習フローは、実施した検証ごとに [VALIDATION.md](VALIDATION.md) へ記録します。ブラウザの自動テストと、Mac・Safariや支援技術の実機確認を区別します。図示や表示の改善を、教材全体の専門家監修の完了とは扱いません。
