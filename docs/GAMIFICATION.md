# クエスト・経験レベル・達成バッジ

## 使い方

ホームの「今日のクエスト」で、学習・クイズ・単語の復習へ進めます。「経験レベル」にはXPの積み重ねを表示します。バッジを開くと獲得条件と進み具合が分かり、「すべてのバッジを見る」から学習記録のコレクションへ移動できます。

学習を続ける小さな目標です。すべてのクエストを終える必要はなく、ハート制、誤答の減点、競争ランキングは設けません。本文16px・学習説明18pxの読みやすさと、必要な解説を開いて読める構成も維持します。

## 今日の3クエスト

| 目標                  | 数える記録                                           |
| --------------------- | ---------------------------------------------------- |
| 1レッスンに取り組もう | その日に終了し、結果を振り返った受講。合否を問わない |
| 5問に取り組もう       | その日に終了した受講の確定回答。正誤を問わない       |
| 1語を復習しよう       | 答えを確かめ、記録したSRSの自己評価                  |

端末のローカル日付でその日の取り組みを集計します。日付が変わるとクエストの進み具合が切り替わり、過去のXP・完了・バッジは保持します。途中のクイズは保存しないため、受講結果の記録までは日次の解答数に加えません。

復習する語が未登録なら単語帳から選べます。登録済みでも期限前なら、次の予定が来てから取り組めます。達成のために復習予定を早めたり、単語を自動登録したりしません。クエストに追加XPやレッスンを解放する効果はありません。

## 経験レベル

経験レベルは初回のレッスン完了で獲得したXPの目安です。タイ語の習熟度や発音の評価ではありません。通常は100XPごとに上がり、現在のコースは最後の10XPを区切りとして、全1210XPでレベル14のXPゴールに達します。

| 獲得XP     | 経験レベル             |
| ---------- | ---------------------- |
| 0〜99      | 1                      |
| 100        | 2                      |
| 890        | 9                      |
| 1200〜1209 | 13                     |
| 1210       | 14・現コースのXPゴール |

再受講・単語復習・クエスト・バッジで追加XPを付けません。初回回答による80%以上の完了条件、前提レッスン、既存のXP付与条件を引き続き使います。

## 8種類のバッジ

| バッジ              | 条件                           |
| ------------------- | ------------------------------ |
| はじめの一歩        | 初めてのレッスンを完了         |
| 学びのリズム        | 5つのレッスンを完了            |
| 最初の章を歩いて    | 最初の章の全レッスンを完了     |
| 3日、ことばにふれる | 累計3日の受講記録              |
| 7日、ことばにふれる | 累計7日の受講記録              |
| 思い出す一歩        | 初めて単語の復習を記録         |
| 復習の習慣          | 単語の復習を累計10回記録       |
| 学びの地図を一巡    | 現在のコースの全レッスンを完了 |

日数のバッジは連続を要求しません。復習のバッジは語数や習熟度を表さず、自己評価を記録した回数です。完了・学習日・カードの累計復習回数から表示するため、追加前の記録や、復習履歴を最新1000件へ絞った後の累計も使えます。

## レッスンと復習の達成表示

クイズは各問の確定状態を表示し、その受講で2問以上続けて正解すると小さな連続正解表示が出ます。誤答には従来の理由と再学習への導線を示し、点数を減らしたり失ったものを演出したりしません。連続正解自体は保存・XP・前提の対象にしません。

合格後に「レッスンを完了する」を押すと、短い紙片演出を表示します。演出は操作に対応して一度だけ始まり、移動・再挑戦で取り消し、動きを減らす設定では表示しません。再受講の追加XPが0の場合も、その回の合格完了は知らせます。

レッスンとSRSの終了画面では、その回で保持したレベル・獲得済みバッジとの差分から、今回増えたバッジや経験レベルを表示します。画面を開いただけ、記録の復元、再読み込みをきっかけに過去の達成を演出しません。追加の効果音は作らず、既存の初期オフ・音量・教材音声優先の設定を保ちます。

## 記録と実装の境界

新しいlocalStorageキーや保存版はありません。受講進捗の `thai-learning.progress.v1` とSRSの `thai-learning.review.v1` から表示用の状態を導出します。バッジ一覧を見るだけでは保存内容を書き換えません。元の記録を消した場合は、その記録から導出する達成表示も変わります。

`src/lib/gamification.ts` が純粋な集計、`use-game-progress.ts` がProviderの読込みと時計、`game-dashboard.tsx` がホーム・学習記録の共通表示、`completion-rewards.tsx` と `lesson-celebration.tsx` が終了時の表示を担当します。ローカル日付、未来や未知の課・設問、完全重複の回答に対応し、読込み中の空状態を達成扱いにしません。

語彙・文法・音声の監修状態、マイク・録音・音声認識の扱いは従来どおりです。認証・クラウド同期・AI会話・公開デプロイには進めません。実施したテストとPC・スマートフォン、動きを減らす設定の確認範囲は [VALIDATION.md](VALIDATION.md) を参照してください。
