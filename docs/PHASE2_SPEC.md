# Phase 2：タイ文字の本格的な読み書き

ユーザーの明示依頼に基づく開発対象。Phase 1の6レッスン・進捗・XP・字体切替を維持し、文字学習と書取りを拡充する。Phase 3以降には自動的に着手しない。

## 提供する学習

- 子音44文字を文字名・初頭音・末子音・子音クラス・例語・確認状況とともに参照できる。
- 現在の通常の綴りで使われない ฃ / ฅ を廃用字として区別し、ฑなどの読み分けがある文字を単一の確定音で扱わない。廃用字の用例は対応する現代の綴りであると明示する。
- 母音の長短・配置・組み合わせ・特殊表記を、独立した `VowelPattern` データで扱う。基本9長短対18形・二重母音3長短対6形・特殊／変化形8形、計32形を収録する。図示用の `-` と実際の綴りを区別し、全ての綴りの網羅は主張しない。
- 文字・日本語名・語義で検索し、子音クラスや母音の長短で絞り込める。
- Part 2に第2章（子音5レッスン）・第3章（母音3レッスン）を追加する。各レッスンは解説・比較・5問の演習・振り返りで構成する。追加は8レッスン40問、全体は3章14レッスン70問。
- 第1章の `five-tones` 完了から前提をつなぎ、既存の80%合格・初回のみXP・ブラウザ保存のルールを再利用する。既存の6つのLesson IDと保存版 `1` を変更しない。既存の240XPに追加330XP、合計570XPとなる。文字ノート・書取りは補助教材として直接開ける。

## 書く体験

- 文字ノートから書取り画面へ進み、全44子音と32母音パターンの用例を選べる。母音は配置を確認するため、図示の `-` ではなく用例全体を書く。比較用音節には語義を付けない旨を表示する。
- 標準のループあり字体を薄い手本に使い、なぞり書きと手本なし練習を切り替える。全体の字体スイッチを切り替えても、書取りの手本はループありに固定する。
- マウス・タッチ・ペンのPointer Eventsに対応し、用紙の大きさが変わっても筆記がずれたり消えたりしない。
- 一画取り消し、全消去、補助線を用意する。描いた画数は操作の記録で、正しい筆画数や点数ではない。
- 筆順は、字形のフォント輪郭から推測して作らない。独立した出典・利用条件・確認状況を持つ軌跡データを使用する。
- `ก`・`ง`・`จ`・`ม` の4字に限り、MITライセンスの手録り軌跡によるSVGの参考運筆アニメーションを提供する。再生、一筆ずつ表示、リセットができ、動きを減らす設定を尊重する。
- 4字も標準筆順は未検証・専門家監修前であり、正しい筆順の模範や採点基準とは扱わない。`ReferenceStrokeGuide` に出典固定コミット・ライセンス・照合日と `standardStrokeVerified: false` を保持する。残り40子音・全母音の未確認アニメーションは提供しない。
- 自動採点、筆順評価、XP加算、書取りの進捗・線の保存、録音・発音比較は今回実装しない。描いた線は文字の変更・画面移動で消える。

`src/data/course.ts` を全体の参照先とし、既存 `curriculum.ts` の第1章、追加 `phase-two.ts`、`alphabet.ts` の出典を統合する。文字と母音は `alphabet.ts`、参考運筆例は `stroke-guides.ts` と `stroke-trajectories.json`、学習者の入力は `handwriting.ts` に分ける。既存の第1章データを破壊せず、教材データとUIを分離する。

## 教材の確認

Unicode公式資料による文字コード・名称の限定照合と、IPA・声調・語義・自然な例文の専門家監修は区別する。教材全体を専門家監修済みとは表示しない。新しい例語は疑わしい用法を避け、出典と確認状況を保持する。

筆順資料のライセンスだけで、その順番が教育的に正しいとは判断しない。4字の運筆例は出典の記録軌跡と利用条件の限定照合であり、正式な標準筆順の監修は未完了である。詳細は [PHASE2_STROKE_RESEARCH.md](PHASE2_STROKE_RESEARCH.md) と [CONTENT_SOURCES.md](CONTENT_SOURCES.md) に残す。

## 検証

型・Lint・ビルド、既存の単体・E2Eに加え、44文字とクラス別内訳、教材の前提参照、母音対、書取りの座標変換・履歴、マウスとタッチ、画面サイズ変更、字体切替を検証する。描画の成功を筆順の正しさや発音能力の検証と混同しない。
