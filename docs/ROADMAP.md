# 開発ロードマップ

## 方針

カリキュラムと教材の正確性を先に整え、操作できる小さな学習体験を完成させてから広げる。Phase 1のMVP、Phase 2の文字学習・書取り、Phase 3の音節・声調規則と、追加依頼の文字入力・録音練習を引き継ぎ、ユーザーの明示依頼でPhase 4の語彙・文法・復習を実装した。現在は全7章30レッスン・150問・初回完了で1210XP。Phase 5、公開環境へのデプロイ、外部サービス連携へは自動的に進まない。

## 追加依頼：文字を覚える集中トレーニング

文字の暗記に苦労する利用者向けに、カリキュラムから独立した `/character-practice` を追加する。詳細は [CHARACTER_TRAINING.md](CHARACTER_TRAINING.md)、実行した検証は [VALIDATION.md](VALIDATION.md) に記録する。

- 全44子音から2〜8字を選択。初期4字 ก・ม・น・ง、基本セット、似た字のセットを用意する。
- 「ペアさがしで遊ぶ」で音声・読み方カードとタイ文字を組み合わせる。正解ペアを固定してその回のコレクションへ並べ、誤答は理由と再試行を用意する。制限時間・ハート・減点は設けない。
- 選択した全2〜8字を各周1回ずつ扱い、「シャッフルしてもう1周」でカードと文字を並べ替えて2周。合計4〜16ペアで、保存・XP・バッジ・SRS・クエストは変更しない。任意の「8問で確かめる」だけが既存クイズへつながる。
- 音声ペアは手がかり選択後の明示再生と正常終了を必要とし、対象・周の変更で遅延通知を無効にする。非対応・失敗時は「読み方でペアさがし」で同じセットの1周目から始め直し、実際の形式をクイズへ渡す。
- 大きな字形と字母名・例語の音声確認から8問チャレンジへ進み、字母名を聞いて文字を選ぶ。絵の手がかりを使わず、即時の正誤・理由と音声の聞き直し、間違えた文字の再練習をつなぐ。
- 選べる形式は「音声から文字」「読み方から文字」の2つ。日本語の名詞や絵から当てず、完全な字母名の音声、または最初の音節IPAとUnicode名の英字表記から字形を選ぶ。英字表記を発音転写とは表示せず、完全なIPA・カタカナを生成しない。
- 新規保存時は音声形式。読み方形式は既存ID `name-to-letter` を使い、旧 `mixed` / `letter-to-sound` は画面内で読み替える。保存キー・版 `1`・文字別記録を維持し、開始操作まで旧形式を書き換えない。
- 音声は明示再生し、正常終了後だけ回答・スキップを使える。取消し・再生失敗・タイ語音声なしは理由と読み方形式への切替を示し、未終了の音声練習を破棄する。読み方形式では音声を任意とし、表示だけで答えられる。
- 完了した回の文字別記録を `thai-learning.character-training.v1` へ独立保存。不正データを自動上書きせず、保存失敗時もタブ内で練習する。
- ホーム・メニュー・文字ノートから開始。字体切替と任意の端末TTS、既存のSE設定を利用し、XP・レッスン解放・SRS・クエスト・バッジを変えない。

母音を含む新しい問題形式、記憶確率の推定、発音採点、筆順の追加はこの依頼の範囲に含めない。字母名・初頭音・日本語訳などの専門家監修は引き続き未完了。

## 次の開発を決める前に

Phase 1〜4の操作性を実際の初学者で確認し、教材を専門家がレビューする。全44子音と用例のIPA・声調、低頻度母音、参考運筆例と標準筆順の区別、声調と先行子音、初級文法の用法・例文の自然さを優先する。音声素材の利用条件と対象語との対応も確認する。誤解を招く解説、問題の難易度、文字の可読性、復習間隔を改善し、追加教材は出典と前提を確認しながら小さな単位で導入する。
