# 開発ロードマップ

## 方針

カリキュラムと教材の正確性を先に整え、操作できる小さな学習体験を完成させてから広げる。今回の実装はPhase 1まで。Phase 2以降には自動的に着手しない。公開環境へのデプロイや外部サービス連携も別の作業として扱う。

## Phase 1：学習アプリの基本体験

機能実装済み。テストの実行結果・件数はREADMEおよび作業完了報告に記載する。教材はすべて未検証の教材案として区別しており、専門家の監修は未完了。

- [x] プロダクト仕様・カリキュラム・アーキテクチャ・開発ルールの日本語文書。
- [x] Next.js、TypeScript、Tailwind、共通UI、Vitest、Playwrightのセットアップ。
- [x] Dashboard、Roadmap、Lesson、基本文字ライブラリ、Progressの5画面。
- [x] 第1章「タイ語の文字と発音の基礎」の6レッスン、10子音、合計30問の構造化教材。
- [x] Learn / Explore / Practice / Review、選択式・文字識別、正誤・理由表示、完了結果。
- [x] 80%以上の理解度による完了、前提による解放、初回のみのXP、再受講時の最高正答率更新。
- [x] localStorageの版付き保存、ローカル日付による学習日・連続日数、破損データの検証、書き込み失敗の表示、通常の複数タブ更新への対応。
- [x] 型チェック、ユニットテスト、本番ビルド、主要フローのE2E、PC・モバイル表示を検証するための構成。
- [ ] タイ語教育の専門家による教材全体の監修。

完成の判定は [PRODUCT_SPEC.md](PRODUCT_SPEC.md) の条件による。出典との照合は専門家の監修と区別し、教材の確認状況と音声等の未実装範囲を明示する。

途中の閲覧位置・回答の保存、苦手概念ごとの集計、実測学習時間、SRS、音声・筆順・自動声調判定は未実装。Phase 1では終了した受講結果と学習日を記録する。後続Phaseの機能が完成済みと見える表示は行わない。

## Phase 2：タイ文字の本格的な読み書き

未着手・未実装。子音44文字と母音の教材を拡充し、文字ライブラリを充実させる。検証した筆順資料を確保してからSVGアニメーションとなぞり書きを導入する。マウス・タッチ操作に対応する。自動採点は必要性と精度を検証してから扱う。

## Phase 3：発音・声調の学習

未着手・未実装。生音節・死音節、子音クラス、声調記号、先行子音、子音連続を段階的に学べる教材を追加する。UIと独立した声調判定モジュール、例外辞書、判定不能の扱い、規則のユニットテストを整える。ライセンスと品質を確認した音声素材で比較・リスニングを提供する。

## Phase 4：語彙・文法学習

未着手・未実装。語彙と文法リファレンス、例文、空欄補充・並べ替えなどを追加する。学習履歴を活用したSRS、復習予定、苦手分野の誘導と詳細統計を導入する。XPと習熟度を混同しない。

## Phase 5：実践学習と高度化

未着手・未実装。会話シナリオ、読解・作文、録音と発音比較、AI会話を検討する。必要性が明確になった段階で認証、Supabaseによるクラウド同期、PWA・オフライン対応、公開環境へのデプロイを設計する。利用料金、音声・録音データの扱い、APIキーの安全な管理を導入前に確認する。

## 次の開発を決める前に

Phase 1の操作性を実際の初学者で確認し、教材を専門家がレビューする。誤解を招く解説、問題の難易度、文字の可読性を優先して改善する。追加教材は一括大量生成せず、出典と前提を確認しながら小さな単位で導入する。
