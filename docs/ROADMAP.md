# 開発ロードマップ

## 方針

カリキュラムと教材の正確性を先に整え、操作できる小さな学習体験を完成させてから広げる。Phase 1のMVP、Phase 2の文字学習・書取りに続き、ユーザーの明示依頼に基づいてPhase 3の音節・声調規則を追加する。Phase 4以降には自動的に着手しない。公開環境へのデプロイや外部サービス連携も別の作業として扱う。

機能実装済み。テストの実行結果・件数は [VALIDATION.md](VALIDATION.md) に記載する。教材はすべて未検証の教材案として区別しており、専門家の監修は未完了。

- [x] プロダクト仕様・カリキュラム・アーキテクチャ・開発ルールの日本語文書。
- [x] Next.js、TypeScript、Tailwind、共通UI、Vitest、Playwrightのセットアップ。
- [x] Dashboard、Roadmap、Lesson、基本文字ライブラリ、Progressの5画面。
- [x] 第1章「タイ語の文字と発音の基礎」の6レッスン、10子音、合計30問の構造化教材。
- [x] Learn / Explore / Practice / Review、選択式・文字識別、正誤・理由表示、完了結果。
- [x] 80%以上の理解度による完了、前提による解放、初回のみのXP、再受講時の最高正答率更新。
- [x] localStorageの版付き保存、ローカル日付による学習日・連続日数、破損データの検証、書き込み失敗の表示、通常の複数タブ更新への対応。
- [x] 型チェック、ユニットテスト、本番ビルド、主要フローのE2E、PC・モバイル表示を検証するための構成。
- [ ] タイ語教育の専門家による教材全体の監修。

完成の判定は [PRODUCT_SPEC.md](PRODUCT_SPEC.md) の条件による。出典との照合は専門家の監修と区別し、教材の確認状況と音声等の未実装範囲を明示する。

Phase 1では終了した受講結果と学習日を記録する。途中の閲覧位置・回答の保存、苦手概念ごとの集計、実測学習時間、SRSは現在も未実装。声調判定の追加範囲は下記のPhase 3に記載し、未対応の解析まで完成済みと見える表示は行わない。

## Phase 2：タイ文字の本格的な読み書き

文字学習・書取りの機能を実装。標準筆順として監修済みの教材は未完成。詳細は [PHASE2_SPEC.md](PHASE2_SPEC.md) と [PHASE2_CONTENT.md](PHASE2_CONTENT.md) を参照。

- [x] 中9・高11・低24の全44子音。廃用字 `ฃ`・`ฅ`、`ฑ` の複数の読みへの注記。
- [x] 基本9長短対・二重母音3長短対・特殊／変化形8の32母音パターン。
- [x] 文字ノートの子音／母音切替、検索、クラス・長短絞り込み、用例・IPA・出典表示。
- [x] 第2章5・第3章3の8レッスン40問を追加。第1章と合わせ3章14レッスン70問、初回完了で合計570XP。
- [x] 第1章の旧6レッスンと保存IDを維持。前提、初回XP、localStorage版 `1` を再利用。
- [x] 44子音と32母音用例のなぞり書き・手本なし練習。標準のループあり手本、補助線、1本戻す、全消去。
- [x] マウス・タッチ・ペン入力、正規化座標によるリサイズ対応。書取りは採点・XP・保存の対象外。
- [x] MITライセンスの手録り4字（ก・ง・จ・ม）の参考運筆アニメーション。出典・利用条件と `standardStrokeVerified: false` を保持し、専門家監修前と表示。
- [x] 文字・母音・章・前提・XP・入力座標の整合性、主要フローを確認する自動テストの拡充。
- [ ] 全44子音・32母音・追加8レッスンの語義、IPA、声調、解説に関する専門家レビュー。
- [ ] 標準筆順としての検証・監修。現状は4字の参考運筆例のみで、残り40子音・全母音にはアニメーションを提供しない。

4字の参考運筆例は、利用条件と記録軌跡を出典と照合したもの。筆順の正確性を検証済みとは扱わず、描いた線を点数や正しい画数に変換しない。自動採点・高度な筆順評価は未実装のままとする。

## Phase 3：発音・声調の学習

音節・声調規則の教材とラボを実装。録音音声は未収録で、端末合成音声と明示した任意の練習を追加する。詳細は [PHASE3_SPEC.md](PHASE3_SPEC.md)、照合範囲は [CONTENT_SOURCES.md](CONTENT_SOURCES.md)、実行したテストは [VALIDATION.md](VALIDATION.md) を参照。

- [x] 第4章「音節と声調のしくみ」4レッスン：音節分解、生音節・死音節、無記号の中・高子音、低子音の死音節と母音長。
- [x] 第5章「声調規則を使って読む」4レッスン：声調記号、真正子音連続・先行子音の導入、音の対立、総合的な読み。
- [x] 追加8レッスン・40問・320XP。全5章22レッスン・110問・890XP。
- [x] 既存14個のLesson ID、570XP、回答履歴、保存版`1`を維持。第3章の完了から継続。
- [x] UIから独立した純粋な声調判定エンジン。クラス・母音長・末音・記号・既知の初頭構造を入力し、生死・有効クラス・声調・判定理由を返す。
- [x] 不正・不足した分析や未対応の組み合わせを判定不能にし、根拠のない声調を表示しない。
- [x] 32語の登録カタログと完全一致検索。初頭・母音・末子音、IPA・訳・注記・出典を保持。
- [x] `/pronunciation`の発音・声調ラボ、5声調の模式図、条件を手動変更する規則確認。ラボにXPや合否は設けない。
- [x] 出典・確認状況・理由を伴う辞書補完の仕組み。現在の32登録語に例外指定はなく、網羅的な例外辞書ではない。
- [x] 規則の主要分岐、未対応条件、不正入力、辞書補完、登録語との整合、旧進捗からの継続を確認するテストの追加。
- [x] 端末のタイ語合成音声（未監修）による確認と任意の聞き分け3問。声の非対応・非同期取得・再生エラーを扱い、XPや進級条件に使わない。
- [ ] 再配布条件と語の対応を確認した録音教材、音声の専門家監修。調査先の接続制限・ファイル欠落・ライセンス未確認のため、今回は未収録。
- [ ] 追加教材と32語の語義・IPA・声調・初頭分析に関する専門家レビュー。
- [ ] 任意のタイ語文字列の音節分割、一般的な綴り解析、網羅的な例外辞書。現在の判定対象は明示した分析条件と登録語に限定。

声調規則の基本対応は参照資料との限定的な照合を行い、単語の発音情報・語義・自然さの専門家監修とは分けて管理する。5声調の模式図は録音の実測ピッチではなく、音の高低の概略。録音・発音採点やAI音声会話は今回追加しない。

## 次の開発を決める前に

Phase 1〜3の操作性を実際の初学者で確認し、教材を専門家がレビューする。特に、全44子音と用例のIPA・声調、低頻度母音の扱い、参考運筆例と標準筆順の区別、声調の条件と先行子音の適用範囲を優先する。音声の導入では、素材の利用条件と対象語との対応を記録する。誤解を招く解説、問題の難易度、文字の可読性を改善する。追加教材は一括大量生成せず、出典と前提を確認しながら小さな単位で導入する。
