# 恋愛の場面で使うタイ語

2026-11-04の追加依頼により、恋愛ストーリーの語学活動を専用の15ターンへ変更する。日本語の恋愛の場面と無関係な店員役・トイレの道案内を挟まず、目の前の相手への返事としてタイ語を使う。街・学園、男女6人、各話の2ルートで同じ学習の軸を共有する。

## 5話の積み上げ

| 話ID | 場面と伝えたいこと | 代表的な表現 |
| --- | --- | --- |
| `meet` | 挨拶、話しかける誘いへの承諾、会えてうれしい | `คุยด้วยได้ไหม`、`ดีใจที่ได้เจอคุณ` |
| `cafe` | 隣席を受け入れ、もっと話し、一緒に出かける | `นั่งด้วยได้ไหม`、`อยากคุยกับคุณ`、`ไปด้วยกัน` |
| `likes` | 褒め言葉へのお礼、好きな相手、会えないときの気持ち | `ชอบคุณ`、`คิดถึงคุณ` |
| `market` | 明日の予定、二人で出かけたい気持ち、待ち合わせ | `พรุ่งนี้ว่างไหม`、`อยากไปกับคุณ`、`เจอกันพรุ่งนี้` |
| `walk` | 別れ際の再会の約束と、寝る前のひと言 | `อยากเจอคุณอีก`、`ฝันดี` |

登録した丁寧詞を各モデルに添える。女性の質問は `คะ`、平叙・応答は `ค่ะ`、男性モデルは `ครับ`。プレイヤーの返答では両方の登録した丁寧な形を受け付ける。初めはお手本を確認し、語句の組立・会話本番3問・前の話の表現・最大1回の言い直しへ進む。

成人同士の近い距離、耳元のひと言、別れがたい夜など、会話を交わしたくなる場面へつなげる。キスや関係を進める日本語の選択は、語学の正誤から分けたまま扱う。各問題は「あなたと会いたいと伝える役」のように伝える内容を示し、利用者本人の恋愛感情や、実生活で断る選択を採点しない。

## 教材と音声の扱い

`src/data/romance-dialogue.ts` が52語句（従来36＋追加16）と15ターンを持つ。既存の本編40語、独立会話34語やSRSへ語句を自動追加しない。追加16語句の辞書形IPAを実取得の固定資料と照合し、一部の語義も辞書と照合した。全文のIPA、例文・日本語訳・丁寧詞や自然さの専門家監修は未完了で、教材は `unreviewed` とする。確認範囲・資料・ライセンスは [ROMANCE_DIALOGUE_SOURCES.md](ROMANCE_DIALOGUE_SOURCES.md)。

既存の端末TTSを明示操作で使い、表示や次の問題で自動再生しない。未監修・通信の説明、非対応時の文字での継続、音声優先と既定オフの効果音を保つ。新しいAPI・録音・発音採点は追加しない。

## 保存と以前の記録

話ID、各話3問、組立1問、支援と前提、好感度の計算、4つの保存キーと版1は維持する。旧記録にない新しい問題の解答履歴を推定しない。活動の各話に任意の `curriculumId: "romance-dialogue-2026-11"` を追加し、新しい教材での明示的な終了時だけ記録する。重複した旧セッションの再送信では付与しない。

以前の記録も読み込め、物語の解放・好感度・思い出・物語選択は保持する。新教材をまだ行っていなければ「以前の会話の記録」「新しい恋愛の表現はこれから」と示し、会話パスポートの新しい完了数へは数えない。以前に解放した後半の話から再演する場合も、初めての表現はヒントで確認できる。従来の3問形式 `?view=classic` でも会話内容は新しい恋愛表現に揃える。

実行した検証と未確認の範囲は [VALIDATION.md](VALIDATION.md) に記録する。
