# 本編レッスンの発見カードとめくり練習

## 目的と範囲

全30レッスンのLearn・Exploreに、短く読む、手を動かして確かめる体験を追加する。既存の教材を1枚ずつ扱い、まとまった本文を最初からすべて読む負担を減らす。Thai、IPA、意味、注意書き、出典・確認状況は既存データをそのまま使う。新しい発音・声調の分析や例文は生成しない。

## 学習の流れ

Learnの「今日のミッション」は最初の学習目標と、その課の解説カード・確認カード・クイズの件数を表示する。すべての学習目標と前提レッスンは、詳細を開いて確認できる。

「発見カード」は `Lesson.blocks` を順に1枚ずつ表示する。前後の移動と番号からの選択に対応し、明示的なチェックでその画面内の読書メモを残せる。「まとめて読む」では全カードの解説、例語、注意、詳しい本文を従来どおり参照できる。チェック数は理解度・習熟度ではなく、チェックした枚数である。

Exploreの「めくって確認」は任意のウォームアップ。`Lesson.explore` のThaiを見て読み方・意味・ポイントを思い出し、「答えをめくる」で既存のIPA・意味・注記を表示する。「もう一度みたい」で選んだカードだけ、最初の一巡が終わった後に1回読み返す。読み返しを繰り返す無限の待ち行列は作らず、終わったら明示操作で新しい一巡を始められる。

「めくったカード」は初めて答えを開いた枚数を数える。同じ答えを再度開いても増やさず、正解数・記憶率・習熟度として表示しない。音声を聞かなくても、答えの表示と先への移動ができる。

従来の比較カード、任意の文字入力・録音は引き続き使える。発見カードのチェックやめくり練習の終了は必須条件にしない。「文字と音を確認する」「練習に進む」や段階ナビゲーションから、自分のペースで先へ進める。

## 採点・保存・音声の境界

- 発見カードのチェック、めくり練習の進行・読み返し対象はReactの一時状態だけで保持する。画面から離れた後の復元は行わない。
- 保存キー・版 `1`、全7章30レッスン・150問・初回合計1210XP、前提条件は変更しない。追加のXP・クエスト・バッジ・SRS登録・予定は作らない。
- 必須の5問は初回確定回答で採点し、正答率80%以上で完了できる。初回完了だけのXP付与、解答後の理由、誤答の振り返りを維持する。
- カードの表示、移動、チェック、めくり、読み返し、終了表示でSEや教材音声を自動再生しない。
- 端末TTSは対応するThaiの明示的な再生だけに使う。図式や子音位置の記号は読み上げず、タイ語の声がない場合は他言語で代用しない。
- TTSは未監修の端末合成音声と表示し、提供元へ通信する場合があることを操作前に知らせる。録音・音声認識・録音再生との既存の優先制御を守る。

教材の専門家監修、発音・声調の採点、学習内容のクラウド同期、Phase 5の実装はこの追加に含めない。

## 実装と確認

`LessonDiscovery` と `LessonRecallGame` を `LessonPlayer` へ組み込む。めくり練習の状態遷移は `src/lib/lesson-recall.ts` に分け、UI・保存・時計・音声から独立させる。カード内の図は既存の `ExampleVisual` による明示済みの分析だけを使う。

確認対象は、全30課の元データ順の保持、答えを開く前の移動防止、一度だけの読み返し、重複操作、本文全体へのアクセス、キーボード・文字拡大・狭い画面、保存・XP・既存の採点への非干渉。実行した検証と限界は [VALIDATION.md](VALIDATION.md) に記録する。
