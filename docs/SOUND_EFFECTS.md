# 効果音

## 使い方

画面上部の「効果音」を開き、「効果音を使う」をオンにします。音量は0〜100%で調整でき、「効果音を試す」で短い確認音を再生できます。初期設定はオフ、音量は35%です。設定の変更はすぐ反映し、オンや音量の変更だけでは音を鳴らしません。ダイアログは閉じるボタンかEscapeキーで閉じられます。

| 場面                                                   | 効果音                     |
| ------------------------------------------------------ | -------------------------- |
| 必須クイズ・文字トレーニングの最初の回答を確定したとき | 正解／誤答を知らせる短い音 |
| 本編の冒険・ミックス練習の各カードで最初の回答を確定したとき | 同じ正解／誤答の短い音 |
| 合格後に「レッスンを完了する」を押したとき             | レッスン完了のチャイム     |
| 本編の冒険で明示的な合格記録が受け付けられたとき       | 同じレッスン完了のチャイム |
| 1語以上を自己評価し、その回のSRS復習を終えたとき       | 復習終了のチャイム         |
| ペアさがしで組合せを選んだとき                         | 正解／誤答を知らせる短い音 |
| ペア2周終了後に完了・クイズへの移動を操作したとき      | 同じ復習終了のチャイム     |
| 8問の文字トレーニングを終える操作をしたとき            | 同じ復習終了のチャイム     |

再受講で追加XPが0の場合も、合格後の完了操作では鳴ります。SRSの個々の自己評価、レッスンの任意文字入力、音声認識結果の一致では正解音を鳴らしません。効果音の有無は正答率・XP・前提・復習予定を変えません。音量0%・オフ・非対応の環境でも、画面の正誤と理由の表示で学習を続けられます。文字トレーニングも問題の表示・保存復元では鳴らさず、8問の最初の回答確定、ペアさがしの各組合せ試行、終了の明示操作に対応します。ペアは誤答後の再試行にも反応しますが、カード選択や周の表示だけでは効果音を再生しません。音声カードを押して流れる字母名のTTSとは区別します。2周が自動的にそろった表示から終了音を鳴らさず、その後の完了・クイズへの移動操作にだけ復習終了のチャイムを使います。音声問題は字母名の正常な再生終了後に答えを確定でき、再生中の効果音は抑止されます。取消し・再生エラーを正解や発音評価の音で知らせません。

本編の冒険・ミックス練習では、必須問題・既習問題・間を空けた想起・再挑戦の各カードで、最初に答えを確定した操作へ既存の `correct` / `incorrect` を対応させます。同じ問題が別のカードとして再登場したときは再び鳴らせますが、同じカードの二重操作では重ねて鳴らしません。練習の音は成績・XP・保存対象を増やしません。

本編の `lesson-complete` は、利用者が合格した受講の記録を操作し、既存の `finishLesson` が結果を受け付けた場合にだけ要求します。開始・次のカード・答えの展開・振り返りの表示・ミックス練習の終了、結果が受け付けられず例外になる場合は、終了音を鳴らしません。localStorageへの書込みが拒否されても、このタブのメモリ内で受け付けた完了は完了音の対象です。その場合は保存できていない警告を維持し、保存済みとは表示しません。新しいSE種別や音源は追加せず、初期オフ・既存の音量設定・教材音声の優先を維持します。

## 音声教材との関係

4種類の効果音はアプリ独自の短い正弦波の組合せをWeb Audio APIで生成します。外部の音源・API・有料サービスは追加しません。タイ語の発音見本やリスニング教材ではなく、発音・声調・語彙習熟度を評価する音でもありません。

教材の読み上げ（TTS、文字トレーニングの字母名・例語を含む）、マイクの許可待ち・録音、音声認識、自分の録音の再生を優先します。これらの使用中は効果音を抑止し、始まった場合は再生中・開始待ちの効果音を取り消します。抑止された効果音を後からまとめて鳴らすことはありません。画面移動、タブが非表示になった場合、ページ離脱でも再生を止めます。

音声の開始は利用者の操作に対応させ、画面表示・保存設定の復元・他タブの設定変更をきっかけに自動再生しません。ブラウザが再生を拒否した場合も、学習を止めず、設定画面で状況を伝えます。

## 設定と実装

設定は進捗・SRS・字体と別の `localStorage` キー `thai-learning.sound.v1` に保存します。

```json
{ "version": 1, "enabled": false, "volume": 0.35 }
```

`version` は `1`、`enabled` は真偽値、`volume` は0〜1の有限数だけを受け付けます。不正なJSON・未知版・無効値は無音の初期設定へ戻し、読込みだけで保存内容を書き換えません。利用者が設定を変更したときだけ保存します。保存できない場合は説明し、このタブでは選択を使えます。通常の他タブの設定変更も取り込みますが、端末間同期は行いません。

- `src/lib/sound-preferences.ts`：初期値、保存データの検証・読込み・書込み。
- `src/lib/sound-effects.ts`：4種類の音列、Web Audio API、再生・取消し・リソース解放。
- `src/lib/audio-focus.ts`：教材音声・マイク使用中の効果音抑止。
- `src/components/sound-effects-provider.tsx`：設定と再生の状態、画面・タブ変更時の停止。
- `src/components/sound-settings.tsx`：上部の設定入口、ダイアログ、オン／オフ、音量、試聴。

音の重なり・取消し、保存不正・失敗、操作に対する再生、教材音声との排他を検証します。実行した検査・件数は [VALIDATION.md](VALIDATION.md) を参照してください。自動テストはMac・Safari実機での音響品質や聴きやすさの確認を代替しません。
