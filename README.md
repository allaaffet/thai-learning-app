# Thai Learning — タイ語を、ひとつずつ。

日本語を母語とする成人が、文字・発音の仕組みからタイ語を学ぶWebアプリです。表では発見・音と文字・思い出す問題を混ぜたミッションを遊び、学ぶ順序はカリキュラムと前提知識で管理します。

**Phase 4の語彙・文法・復習と、Phase 5第1段階の会話ミッションを操作できる学習アプリ**です。アカウント登録、APIキー、有料サービスは不要です。

## できること

- ホームと「学習の冒険」：次のミッションへ進む入口と、完了・これからを示す道。前提に沿って30レッスンを解放します。
- 本編ミッション：発見カード・音と文字の確認の間に既習問題を混ぜ、少し間を空けてもう一度思い出す練習と、間違えた問題への再挑戦を行います。1画面ずつ進み、解き直しは各問題1回までです。
- ミックス練習：完了した内容から最大6問。直近の本編で間違えた問題を優先し、別の組み合わせでも練習できます。結果はその回だけで、XPや復習予定を変えません。
- ロードマップと教科書形式：8部のカリキュラム案、第1〜7章の30レッスンを確認。Learn → Explore → Practice → Reviewでじっくり学ぶ方法も残しています。日本語解説、Thai・IPA・意味の比較、4形式の全150問、正誤と理由を扱い、第6・7章で初級の語順・否定・疑問・数量・アスペクト・依頼・比較を学べます。
- 本編の発見カード：解説を1枚ずつ読み、チェックしながら進められます。任意の「めくって確認」では、答えを思い出してから開き、「もう一度みたい」カードだけ一度読み返せます。
- 5問中4問以上でレッスン完了。初回のみXPを付与し、再受講で最高正答率を更新できます。誤答へのペナルティはありません。
- タイ文字ノート：全44子音と32母音パターン、クラス・長短の絞り込み、文字・意味の検索、用例と発音情報。
- 文字トレーニング：19種類の固定セット、全44子音からの2〜8文字の選択、現用42字から4字・8字を選ぶ「おまかせ」。音声・読み方と字形のペアさがしと8問で繰り返せます。未練習・直近の誤答を多めにした組み合わせも選べます。
- 会話ミッション：挨拶・カフェ・買い物・道案内の4シーンで各3回のやりとり。目的に合う返答を選び、理由を見てやり直せます。日本語訳、単語のIPA、任意の端末TTSを参照し、終了した会話の練習済み記録をこのブラウザへ保存できます。
- 書取り：全44子音と32母音パターンの用例を、マウス・指・ペンでなぞる／手本なしで書く練習。ガイド線、1本戻す、全消去に対応。
- ก・ง・จ・มの4字に、出典の記録軌跡を再生する参考アニメーション。標準筆順は未検証・専門家監修前です。他の40字と母音には未確認の筆順を表示しません。
- 発音・声調ラボ：登録済みの32語を初頭子音・母音・末子音に分け、声調の判定理由を順に表示。5声調の模式図と、条件を手動で変える規則の確認ができます。
- 判定は登録語の完全一致に限定し、未登録語や複数音節の語は推測しません。任意のタイ語を自動で音節分割・解析する機能ではありません。
- 単語帳：基本40語を日本語・タイ語で検索し、カテゴリー、IPA、音節、例文、関連レッスンを確認。覚えたい語を復習へ登録できます。
- 文法ノート：8項目の型・日本語との違い・例文中の役割を参照し、関連レッスンへ進めます。
- 復習：登録語の意味を思い出し、答えを表示して自己評価。1・3・7・14・30・60日を基本に、復習予定を保存します。
- 学習記録：直近の解答と苦手概念、関連レッスン、直近7日の活動、SRSの登録・復習状況と8種類の達成バッジ。実測学習時間や習熟度の保証は表示しません。
- ブラウザ内への進捗・復習予定の保存、再読み込み後の復元、保存失敗のお知らせ。
- PC・タブレット・スマートフォン、キーボード操作、ローカル配信のThai対応フォント。
- 例語カード、音節・語順の図、章の進捗、7日の活動グラフで学習内容を表示。本文は16px、学習の説明は18pxを基本にし、補足は開いて読めます。
- 全30レッスンのLearnの例語とExplore、発音ラボ：端末のタイ語合成音声（未監修）で確認。綴りの図式は読み上げません。任意の聞き分け3問はXP・進級条件に使いません。タイ語の声がない端末では理由を表示し、他言語で代用しません。
- 全30レッスンのExploreに、既習語を1語ずつ確かめる任意練習。「文字で答える」は綴りの一致と理由を表示し、「声で確かめる」は見本・IPAと自分の録音を聞き比べられます。
- 自分の録音は最大20秒・5MBで、再生・削除が可能。この画面のメモリだけで扱い、アプリから保存・送信せず、画面移動で破棄します。対応ブラウザでは別の任意機能として、音声認識が返すタイ文字との一致も参考にできます。発音・声調の採点はしません。
- 画面上部の「タイ語の字体」で、標準（ループあり）とループなしを切り替え。選択はこのブラウザに保存されます。
- 画面上部の「効果音」で、クイズ・文字トレーニングの正誤、レッスン完了・復習終了・文字練習終了の短い音を設定。初期設定はオフ、音量は35%です。教材の読み上げ、録音・音声認識・録音の再生を優先します。
- クイズの連続正解を小さく表示し、合格後の完了操作で短い達成演出。動きを減らす設定にも対応します。

**教材は専門家レビュー前の教材案です。** Unicode公式資料による文字名・コード等の限定照合、資料との基本声調表の照合、個々のIPA・声調・語義の検証を区別しています。4字の運筆例も正しい筆順の保証や採点基準には使いません。見本の合成音声と任意練習の教材も未監修です。ネイティブ話者の実録音教材は未収録です。検証済みの標準筆順、書取りの自動採点、任意語の発音解析・発音採点、クラウド同期は未実装です。確認範囲は [教材の出典](docs/CONTENT_SOURCES.md) を参照してください。

詳しく読みたいときは、レッスンの「くわしい説明を読む」、単語の「音節・発音・補足」、文法の「日本語との違い・考え方」を開きます。本文・IPA・出典を省略せず、最初に目に入る情報を絞っています。表示の方針は [画面デザイン](docs/VISUAL_DESIGN.md) を参照してください。

本編はホームまたは `/play` から始めます。新しい解説と例を確認してから、その課の確認5問（チェックポイント）に答えます。途中の既習問題・思い出す問題・再挑戦は練習であり、確認5問の初回回答による成績を上書きしません。先に既習問題が出るため、最初に表示される5問という意味ではありません。教科書形式では「まとめて読む」で解説全体を参照でき、従来のめくり練習・任意入力・録音も使えます。詳しくは [本編の冒険](docs/MISSIONS.md)、[教科書のミニ練習](docs/LESSON_GAMES.md) を参照してください。

## セットアップ

Node.js **24 LTS**（検証版24.19.0）とnpmを使います。`.node-version` に版を記載しています。依存関係は `package-lock.json` で固定しています。

現在の実装は `codex/phase-1-mvp` ブランチにあります。ブランチ名はそのままでPhase 2〜4を追加しています。

```bash
git clone --branch codex/phase-1-mvp https://github.com/allaaffet/thai-learning-app.git
cd thai-learning-app
npm ci
npm run dev
```

ブラウザのアドレス欄に `http://localhost:3000` を入力します。ホームの開始ボタンか、メニューの「学習の冒険」から体験できます。すでにクラウド上のチェックアウトがある場合は、`/workspace/thai-learning-app` で `npm run dev` を実行してください。クラウド環境のブラウザ表示機能の対応状況は利用中のUIに依存します。

すでにMacなどへ取得済みの場合は、起動中のサーバーを `Control+C` で止め、アプリのフォルダで更新します。既存22レッスンの保存済み進捗はそのまま使えます。

```bash
git pull --ff-only
npm ci
npm run dev
```

### 同じWi-Fiのスマートフォンで試す

1. Macとスマートフォンを同じWi-Fiにつなぎます。
2. Macで `npm run dev` を起動し、ターミナルを開いたままにします。
3. Macの「システム設定 → Wi-Fi → 接続中ネットワークの詳細 → TCP/IP」でIPアドレスを確認します。
4. スマートフォンのブラウザで `http://MacのIPアドレス:3000` を開きます。たとえばIPが `192.168.0.221` なら `http://192.168.0.221:3000` です。起動時に別のポートが表示された場合は、その番号を使います。

`next.config.ts` は起動したマシンのIPv4アドレスを列挙し、Next.jsの `allowedDevOrigins` に追加します。開発用接続が拒否されて初期化が止まり、設定・開始ボタンが無効になる問題を防ぎます。許可は実際のアドレスだけで、全ホストを許可するワイルドカードは使いません。Wi-FiやIPが変わった場合は開発サーバーを再起動してください。

更新後もボタンがグレーのままなら、Macで `Control+C` → `git pull --ff-only` → `npm run dev` の順に実行し、スマートフォン側のページも再読み込みします。接続自体ができない場合は、同じWi-Fiか、Macの通信許可、表示されたポート番号を確認します。

学習記録は端末・ブラウザ・接続先アドレスごとに別保存です。HTTPでのLAN接続ではマイクに制限があるため、録音にはHTTPSなどの対応環境が必要です。端末合成音声はタイ語の声が利用できる場合だけ使い、利用できないときは読み方の練習へ切り替えられます。

### Macで古いNode.jsが使われる場合

[Node.js公式サイト](https://nodejs.org/ja/download)からmacOS用の24 LTSインストーラー（`.pkg`）を入れ、ターミナルを開き直します。`node -v` が `v24.…` になれば準備完了です。npmの番号は24である必要はありません。

Anacondaを使っていてエラーに `/opt/anaconda3/bin/node`・`node v6.13.1` が出る場合は、同じターミナルで次を実行し、新しくインストールしたNode.jsを優先します。この変更はそのターミナルだけに適用されます。

```bash
export PATH="/usr/local/bin:$PATH"
hash -r
node -v
npm -v
```

`node -v` が24系になってから `npm ci` と `npm run dev` を実行してください。

24系になったことを確認できたら、次を1回だけ実行すると、新しいターミナルでも公式版を優先できます（標準のzshを使う場合）。古いAnacondaの`base`環境全体を更新する必要はありません。

```bash
printf '\nexport PATH="/usr/local/bin:$PATH"\n' >> ~/.zshrc
```

このクラウド環境ではnpmの標準キャッシュ先が書き込めないため、依存の再インストール時は以下を使います。

```bash
npm ci --cache /tmp/thai-learning-npm-cache
```

本番と同じ構成で確認する場合：

```bash
npm run build
npm run start
```

ポート3000をすでに使用している場合は、開発サーバーを `npm run dev -- --port 3001` で起動できます。開発・本番のサーバーは同じチェックアウトで同時に動かさず、起動中のものを `Ctrl+C` で停止してから切り替えてください。

## Webアプリを公開する

[Vercelでの公開手順](docs/DEPLOYMENT.md) を用意しています。GitHubの `main` をImportし、Next.js・Node.js 24.xでDeployします。アプリ用APIキーやDBの設定は不要です。クラウド環境の「Publish」とは別の操作で、公開先の学習記録はlocalhost・LANとは別保存になります。

## テスト

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

まとめて実行するには `npm run check`。ユニットテストは教材の参照整合性・前提関係、4形式の採点、80%境界、初回回答、XP重複防止、進捗の検証・保存・復元、SRSの予定・履歴・保存データ保護、最新回答による苦手概念の集計、声調規則の主要分岐・判定不能・辞書補完を確認します。

E2Eはビルド済みアプリをPCとスマートフォンの画面サイズで操作します。

```bash
npx playwright install chromium
npm run build
npm run test:e2e
```

Linuxでブラウザの共有ライブラリが不足している場合は、Playwright公式手順の `npx playwright install --with-deps chromium` を使ってください。このクラウド環境はChromiumが導入済みなので、ダウンロードなしで以下を実行できます。

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

テストは必要に応じてポート3000で本番サーバーを起動します。既存サーバーを再利用する場合は、最新のビルドであることを確認してください。結果は `playwright-report/`、スクリーンショットは `test-results/` に出力され、Gitには含めません。

スマートフォンからのLAN接続は、開発サーバーを使う専用テストでも確認できます。起動中の開発サーバーを停止し、プライベートIPv4のネットワークにつないで実行します。本番ビルドは不要です。

```bash
npm run test:e2e:lan
```

このテストはポート3100で新しい開発サーバーを起動し、localhostではなく実際のLANアドレスからPC・Pixel 7相当のChromiumで操作します。設定の有効化、ペアの操作、8問終了・保存・再読み込み、未知のOriginの拒否を確認します。クラウドの導入済みChromiumを使う場合は、同様に `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium` を付けて実行してください。

## 保存と学習ルール

- 保存キーは `thai-learning.progress.v1`。このブラウザ・同じオリジン内だけの保存です。別の端末とは同期しません。
- 正答率は各受講回の各問題で最初に確定した答えから計算します。回答後の選び直しで成績を上げることはできません。
- 必須の空欄入力は前後の空白以外を変えずに比較し、並べ替えは語句IDの順序・重複・欠落を確認します。正誤は固定IDで記録し、入力した文字そのものは保存しません。
- 冒険の受講結果と学習日は終了時の明示的な記録操作で保存します。教科書形式では不合格の結果をクイズ終了時に記録し、合格した受講は「レッスンを完了する」で完了とXPを保存します。
- 冒険に混ざる既習問題・思い出す問題・再挑戦と、最大6問のミックス練習はその回だけの練習です。現在の課の確認5問の初回回答による成績、XP、SRS予定、前提、クエスト・バッジへ加算しません。
- 途中のページ位置や未終了クイズは保存しません。「学習をつづける」は未完了の最初のレッスンに戻ります。
- 再受講でXPは増えず、以前の完了と最高正答率は維持します。学習日・連続日数は利用者のローカル日付を使います。
- 第1章は240XP、第2・3章は330XP、第4・5章は320XP、第6・7章は320XP。全30レッスンの初回完了は合計1210XPです。第6章は第5章最後の `tone-reading-review` の完了から進みます。旧22レッスン・110問・890XPと保存版 `1` は維持します。
- 書取りは採点・XP加算・進捗保存の対象外です。描いた線は文字の変更や画面移動で消えます。薄い手本は全体の字体切替にかかわらず、標準のループあり字体を使います。
- 文字トレーニングは独立した `thai-learning.character-training.v1` に選択設定と終了した8問分の文字別記録を保存します。XP・レッスン解放・SRS・今日のクエストには加算しません。不正な保存内容は自動で上書きせず、画面内で続けられます。
- 会話ミッションは独立した `thai-learning.conversation.v1` に、終了回数・最終終了日時・重複防止用の直近100回のIDだけを保存します。会話履歴・選択した表現・音声は保存せず、XP・前提・SRS・クエストも変わりません。不正な原文は明示的な置換まで保護します。
- 発音・声調ラボもXP加算・進捗保存の対象外です。任意の語の発音を保証する辞書や、録音による発音採点ではありません。
- 任意の文字入力・音声認識・録音は、成績・XP・前提レッスンの解放に使いません。入力内容、認識された文字、録音は学習記録に保存しません。Phase 4の必須の空欄入力・並べ替え問題とは別に扱います。
- 保存先が使用できない場合も、その画面では学習を続けられます。保存できていない旨を表示します。
- 復習予定と直近1000回の自己評価履歴は、進捗と別の `thai-learning.review.v1` に保存します。SRSではXPを加算せず、レッスンの解放にも使いません。未知の版・不正な復習データは上書きせず、画面内だけで続けます。
- 複数タブは保存直前の再読み込みと変更通知で通常の更新を取り込みます。厳密に同時の書き込み・端末間の同期は保証しません。
- ブラウザのサイトデータを削除すると進捗と復習予定も消えます。壊れたJSONや未知の保存版は検証して安全に扱い、読み込みだけで元の保存データを上書きしません。

## 合成音声を使う場合

「端末の合成音声（未監修）」と表示した機能はWeb Speech APIを使います。タイ語の声を端末・ブラウザが提供する場合だけ利用できます。声の名前と言語を表示し、音声提供元への通信があり得る声も区別します。音声ペアのカード、確認する文字、本編のスピーカー付き比較カード、声調ラボの登録語は、選ぶ操作でそのまま聞けます。ページ表示・次の問題・答えの表示では鳴らさず、録音・ネイティブ音声・監修済み発音とは表示しません。声が見つからない場合も、30レッスン・単語帳・文法ノート・復習と声調ラボを利用できます。

読み方形式の音声ボタンは折りたたみを開かずに押せます。単語の復習も、意味の答えを表示する前から音声を聞けます。録音・音声認識中に本編の比較カードを選んでも、録音等を中断して読み上げたり、後から予約再生したりしません。

再配布条件を満たす実録音声は今回確保できませんでした。録音教材の追加と専門家による確認は残課題です。調査内容は [Phase 3資料](docs/PHASE3_SOURCES.md) に記録しています。IPA資料の [出典・ライセンス表示](public/licenses/Thai-IPA-ATTRIBUTION.txt) も同梱しています。

## 効果音を使う場合

画面上部の「効果音」を開き、「効果音を使う」をオンにします。音量を調整し、「効果音を試す」で確認できます。初期設定はオフ、音量は35%。設定は進捗と別の `thai-learning.sound.v1` に保存し、保存できない場合もこのタブでは使えます。

必須クイズと文字トレーニングの最初の確定回答、合格後のレッスン完了、1語以上を自己評価した回の復習終了、8問の文字練習終了で鳴ります。ペアさがしは各組合せの正誤と、2周終了後の明示的な完了・クイズへの移動操作で鳴り、カードを選んだだけでは効果音を再生しません。音声カードを押して流れる字母名のTTSは、ここで扱う効果音とは別です。任意入力・音声認識の一致やSRSの個々の自己評価では鳴りません。読み上げ、マイクの許可待ち・録音、音声認識、録音の再生中は抑止し、画面移動やタブ非表示で停止します。音は独自のWeb Audioによる短い効果音で、タイ語の音声教材・発音評価ではありません。詳細は [効果音](docs/SOUND_EFFECTS.md) を参照してください。

## タイ文字を少しずつ覚える

ホームの「文字をゲームで覚える」、メニューの「文字トレーニング」、または `/character-practice` から始めます。

1. まずは ก・ม・น・ง の4文字。「ペアさがしで遊ぶ」で音声・読み方カードとタイ文字を組み合わせます。1周終えたら「シャッフルしてもう1周」。合った文字が集まり、「2周クリア！」まで何度でも試せます。
2. 音声カードをタップすると、そのまま文字の名前が流れます。同じカードを押すと聞き直せ、最後まで聞いてから文字を選びます。「読み方から文字」はIPAと字母名の英字表記を一緒に見て選び、任意の音声もボタン1回で聞けます。日本語の意味や絵を手がかりにせず、間違えても理由を見て試し直せます。文字を増やすときは全44字から2〜8字を選べます。
3. 慣れたら「8問で確かめる」へ。通常のクイズは最初の確定回答を記録し、結果から間違えた文字を再練習できます。ペアさがしの進行・コレクションは画面内だけで、8問を終えた結果だけをこのブラウザへ保存します。XP・前提レッスン・単語復習の予定は変えません。

「新しい組み合わせ」は現用42字から4字・8字を選びます。未練習の文字や直近のまちがいを多めにする設定も使え、足りない場合は他の文字で補います。固定セットは19種類で、「さらに14種類のセット」から子音クラスや基本音の組を選べます。廃用2字は専用セットだけに含まれます。

「このセットで覚える」から字形と音声を確認し、直接8問へ進む使い方も残しています。ペアさがしは減点・制限時間なしのウォームアップで、文字のコレクションを習熟度として保存しません。

音声は完全な字母名（例：ก ไก่）で、初頭音だけの聞き分けや発音の採点ではありません。初回は音声形式で始まります。タイ語の声がない端末や再生エラー時は、理由を表示して「読み方から文字」へ切り替えられます。読み方には「字母名の最初の音節」のIPAと「字母名の英字表記（Unicode名）」を表示し、音声なしでも答えられます。英字表記は正確な発音転写ではなく、字母名全体のIPAを生成する機能でもありません。以前の形式と文字別記録も引き継ぎ、画面の選択肢はこの2形式へ整理しています。標準／ループなし字体の両方で練習できます。教材・端末の合成音声は専門家監修前で、提供元へ通信する場合があります。詳細は [文字トレーニング](docs/CHARACTER_TRAINING.md) を参照してください。

## 会話ミッションを使う

ホーム・メニューの「会話ミッション」、または `/conversations` から4シーンを選びます。相手のThaiと伝えたい内容を確認し、返答を選びます。日本語訳と単語の読み方は開いて参照でき、ねらいに合わなければ理由を見て選び直せます。全3回を終えて「この会話の練習を記録」を押すと、このブラウザで練習済みになります。途中の選択や会話履歴は保存しません。

台本・訳・自然さは専門家監修前です。語のIPAは文全体の発音転写ではなく、TTSも未監修の端末合成音声です。Phase 5はこのガイド付き練習から開始しており、自由なAI会話、認証・端末間同期、PWA・オフライン対応、公開デプロイは未実装です。詳細は [Phase 5仕様](docs/PHASE5_SPEC.md) を参照してください。

## クエストとバッジを楽しむ

ホームの「今日のクエスト」から、レッスン・クイズ・単語復習へ進めます。合否や正誤に関係なく、終了した受講と記録した復習を数えます。できる分だけ取り組めばよく、復習の期限前は次の予定を待てます。クエストに追加XPや学習の解放条件はありません。

「経験レベル」は獲得済みXPの積み重ね、バッジは完了・累計学習日・復習回数の記念です。過去の記録も反映し、学習記録のバッジを開くと獲得条件を確認できます。タイ語の習熟度・発音評価とは分けます。詳細は [クエストとバッジ](docs/GAMIFICATION.md) を参照してください。

## 単語・文法と復習を使う

単語帳 `/vocabulary` で語を探し、「復習に登録」してから復習 `/review` へ進みます。登録した語はすぐ出題できます。タイ語を見て意味を思い出し、答えを表示して「もう一度」「迷った」「思い出せた」から選びます。各回は開始時に期限が来ていた最大20語です。今答えた語を同じ回で繰り返さず、次の予定に従って学びます。

「もう一度」は10分後、「迷った」は1日後で段階を維持、「思い出せた」は1・3・7・14・30・60日後へ進みます。固定間隔の簡単な方式で、記憶確率や語彙力を採点する機能ではありません。期限前だけなら次の予定を表示します。

文法ノート `/grammar` では型と例文中の役割を確認できます。第6章から学ぶ場合はロードマップで前提の完了を確認してください。ノートの参照とSRS登録は、レッスンの前提未達でも利用できます。説明・訳・用法は専門家の監修前です。

## 文字入力・自分の声で練習する

任意のレッスンを開き、Exploreの「今度は、自分で。」で方法を選びます。飛ばしても通常のクイズへ進めます。

1. **文字で答える**：問題の意味・ヒントからタイ語を入力し、「文字の答えを確認」を押します。前後の空白を除いた完全一致で綴りを確認し、見本・IPA・理由を表示します。発音の判定ではありません。
2. **声で確かめる**：見本の合成音声とIPAを確認してから「録音を始める」を押し、ブラウザでマイクを許可します。最大20秒・5MB。録音を止めて再生し、見本と交互に聞けます。「録音を削除」や方法の切替・画面移動で破棄されます。
3. **音声認識（任意・参考）**：対応ブラウザだけで利用できます。開始前の説明を読んで「音声認識を始める」を押すと、タイ語の認識を試み、約9秒で終了します。音声はブラウザ提供元へ送信される場合があります。表示するのは認識された文字列との一致で、発音・声調・信頼度を採点しません。一致しても正確な発音の証明にはなりません。

Macでタイ文字を入力するには「システム設定 → キーボード → テキスト入力 → 編集 → ＋」からタイ語を追加し、入力メニューで切り替えます。マイクはHTTPSまたは `http://localhost:3000` で利用してください。音声・録音・認識の非対応、マイク拒否、認識エラーの場合も、文字入力や既存の解説・クイズで学習できます。TTS・録音・音声認識は同時に実行しません。

録音機能はアプリから音声を送信せず、この画面のメモリ内で扱います。一方、音声認識と端末の合成音声には、ブラウザ・OSの提供元への通信が発生する場合があります。入力・録音・認識結果をlocalStorageやサーバーへ保存する機能はありません。詳細と確認範囲は [入力・録音練習仕様](docs/LESSON_OUTPUT_SPEC.md) と [検証結果](docs/VALIDATION.md) を参照してください。
