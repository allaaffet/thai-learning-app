# Thai Learning — タイ語を、ひとつずつ。

日本語を母語とする成人が、文字・発音の仕組みからタイ語を学ぶWebアプリです。カリキュラムを軸に、短い解説・比較・演習・振り返りを組み合わせます。

**Phase 3まで操作できる学習アプリ** に、ユーザーの依頼に基づく任意の文字入力・録音練習を追加しています。アカウント登録、APIキー、有料サービスは不要です。

## できること

- ホーム：次に学ぶレッスン、今日の目標、進捗・XP・連続学習日数。
- ロードマップ：8部のカリキュラム案、第1〜5章の22レッスン、前提に基づく解放。
- レッスン：Learn → Explore → Practice → Review。日本語解説、Thai・IPA・意味の比較、選択式・文字識別の全110問、正誤と理由。Phase 3で音節・生死・声調規則の8レッスン・40問を追加しています。
- 5問中4問以上でレッスン完了。初回のみXPを付与し、再受講で最高正答率を更新できます。誤答へのペナルティはありません。
- タイ文字ノート：全44子音と32母音パターン、クラス・長短の絞り込み、文字・意味の検索、用例と発音情報。
- 書取り：全44子音と32母音パターンの用例を、マウス・指・ペンでなぞる／手本なしで書く練習。ガイド線、1本戻す、全消去に対応。
- ก・ง・จ・มの4字に、出典の記録軌跡を再生する参考アニメーション。標準筆順は未検証・専門家監修前です。他の40字と母音には未確認の筆順を表示しません。
- 発音・声調ラボ：登録済みの32語を初頭子音・母音・末子音に分け、声調の判定理由を順に表示。5声調の模式図と、条件を手動で変える規則の確認ができます。
- 判定は登録語の完全一致に限定し、未登録語や複数音節の語は推測しません。任意のタイ語を自動で音節分割・解析する機能ではありません。
- ブラウザ内への進捗保存、再読み込み後の復元、保存失敗のお知らせ。
- PC・タブレット・スマートフォン、キーボード操作、ローカル配信のThai対応フォント。
- 全22レッスンのLearnの例語とExplore、発音ラボ：端末のタイ語合成音声（未監修）で確認。綴りの図式は読み上げません。任意の聞き分け3問はXP・進級条件に使いません。タイ語の声がない端末では理由を表示し、他言語で代用しません。
- 全22レッスンのExploreに、既習語を1語ずつ確かめる任意練習。「文字で答える」は綴りの一致と理由を表示し、「声で確かめる」は見本・IPAと自分の録音を聞き比べられます。
- 自分の録音は最大20秒・5MBで、再生・削除が可能。この画面のメモリだけで扱い、アプリから保存・送信せず、画面移動で破棄します。対応ブラウザでは別の任意機能として、音声認識が返すタイ文字との一致も参考にできます。発音・声調の採点はしません。
- 画面上部の「タイ語の字体」で、標準（ループあり）とループなしを切り替え。選択はこのブラウザに保存されます。

**教材は専門家レビュー前の教材案です。** Unicode公式資料による文字名・コード等の限定照合、資料との基本声調表の照合、個々のIPA・声調・語義の検証を区別しています。4字の運筆例も正しい筆順の保証や採点基準には使いません。見本の合成音声と任意練習の教材も未監修です。ネイティブ話者の実録音教材は未収録です。検証済みの標準筆順、書取りの自動採点、任意語の発音解析・発音採点、SRS、クラウド同期は未実装です。確認範囲は [教材の出典](docs/CONTENT_SOURCES.md) を参照してください。

## セットアップ

Node.js **24 LTS**（検証版24.19.0）とnpmを使います。`.node-version` に版を記載しています。依存関係は `package-lock.json` で固定しています。

現在の実装は `codex/phase-1-mvp` ブランチにあります。ブランチ名はそのままでPhase 2・3を追加しています。

```bash
git clone --branch codex/phase-1-mvp https://github.com/allaaffet/thai-learning-app.git
cd thai-learning-app
npm ci
npm run dev
```

ブラウザのアドレス欄に `http://localhost:3000` を入力します。ホームの「学習をはじめる」から体験できます。すでにクラウド上のチェックアウトがある場合は、`/workspace/thai-learning-app` で `npm run dev` を実行してください。クラウド環境のブラウザ表示機能の対応状況は利用中のUIに依存します。

すでにMacなどへ取得済みの場合は、起動中のサーバーを `Control+C` で止め、アプリのフォルダで更新します。既存22レッスンの保存済み進捗はそのまま使えます。

```bash
git pull --ff-only
npm ci
npm run dev
```

### Macで古いNode.jsが使われる場合

[Node.js公式サイト](https://nodejs.org/ja/download)からmacOS用の24 LTSインストーラー（`.pkg`）を入れ、ターミナルを開き直します。`node -v` が `v24.…` になれば準備完了です。npmの番号は24である必要はありません。

Anacondaを使っていてエラーに `/opt/anaconda3/bin/node`・`node v6.13.1` が出る場合は、同じターミナルで次を実行し、新しくインストールしたNode.jsを優先します。この変更はそのターミナルだけに適用されます。

```bash
export PATH="/usr/local/bin:$PATH"
hash -r
node -v
npm -v
```

`node -v` が24系になってから `npm ci` と `npm run dev` を実行してください。

24系になったことを確認できたら、次を1回だけ実行すると、新しいターミナルでも公式版を優先できます（標準のzshを使う場合）。古いAnacondaの`base`環境全体を更新する必要はありません。

```bash
printf '\nexport PATH="/usr/local/bin:$PATH"\n' >> ~/.zshrc
```

このクラウド環境ではnpmの標準キャッシュ先が書き込めないため、依存の再インストール時は以下を使います。

```bash
npm ci --cache /tmp/thai-learning-npm-cache
```

本番と同じ構成で確認する場合：

```bash
npm run build
npm run start
```

ポート3000をすでに使用している場合は、開発サーバーを `npm run dev -- --port 3001` で起動できます。開発・本番のサーバーは同じチェックアウトで同時に動かさず、起動中のものを `Ctrl+C` で停止してから切り替えてください。

## テスト

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

まとめて実行するには `npm run check`。ユニットテストは教材の参照整合性・前提関係、80%境界、初回回答、XP重複防止、進捗の検証・保存・復元、声調規則の主要分岐・判定不能・辞書補完を確認します。

E2Eはビルド済みアプリをPCとスマートフォンの画面サイズで操作します。

```bash
npx playwright install chromium
npm run build
npm run test:e2e
```

Linuxでブラウザの共有ライブラリが不足している場合は、Playwright公式手順の `npx playwright install --with-deps chromium` を使ってください。このクラウド環境はChromiumが導入済みなので、ダウンロードなしで以下を実行できます。

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

テストは必要に応じてポート3000で本番サーバーを起動します。既存サーバーを再利用する場合は、最新のビルドであることを確認してください。結果は `playwright-report/`、スクリーンショットは `test-results/` に出力され、Gitには含めません。

## 保存と学習ルール

- 保存キーは `thai-learning.progress.v1`。このブラウザ・同じオリジン内だけの保存です。別の端末とは同期しません。
- 正答率は各受講回の各問題で最初に確定した答えから計算します。回答後の選び直しで成績を上げることはできません。
- 受講結果と学習日は、クイズ終了時に記録します。合格した受講は「レッスンを完了する」を押した時点で完了とXPを保存します。
- 途中のページ位置や未終了クイズは保存しません。「学習をつづける」は未完了の最初のレッスンに戻ります。
- 再受講でXPは増えず、以前の完了と最高正答率は維持します。学習日・連続日数は利用者のローカル日付を使います。
- 第1章は240XP、第2・3章は330XP、第4・5章は320XP。22レッスンの初回完了は合計890XPです。第4章は第3章最後の`vowel-compounds`を完了すると開きます。
- 書取りは採点・XP加算・進捗保存の対象外です。描いた線は文字の変更や画面移動で消えます。薄い手本は全体の字体切替にかかわらず、標準のループあり字体を使います。
- 発音・声調ラボもXP加算・進捗保存の対象外です。任意の語の発音を保証する辞書や、録音による発音採点ではありません。
- 任意の文字入力・音声認識・録音は、成績・XP・前提レッスンの解放に使いません。入力内容、認識された文字、録音は学習記録に保存しません。従来どおり22レッスン・110問・最大890XP・保存版 `1` を維持します。
- 保存先が使用できない場合も、その画面では学習を続けられます。保存できていない旨を表示します。
- ブラウザのサイトデータを削除すると進捗も消えます。壊れたJSONや未知の保存版は検証して安全に扱い、読み込みだけで元の保存データを上書きしません。

## 合成音声を使う場合

「端末の合成音声（未監修）」と表示した機能はWeb Speech APIを使います。タイ語の声を端末・ブラウザが提供する場合だけ利用できます。声の名前と言語を表示し、音声提供元への通信があり得る声も区別します。自動では再生せず、録音・ネイティブ音声・監修済み発音とは表示しません。声が見つからない場合も、22レッスンと声調ラボは利用できます。

再配布条件を満たす実録音声は今回確保できませんでした。録音教材の追加と専門家による確認は残課題です。調査内容は [Phase 3資料](docs/PHASE3_SOURCES.md) に記録しています。IPA資料の [出典・ライセンス表示](public/licenses/Thai-IPA-ATTRIBUTION.txt) も同梱しています。

## 文字入力・自分の声で練習する

任意のレッスンを開き、Exploreの「今度は、自分で。」で方法を選びます。飛ばしても通常のクイズへ進めます。

1. **文字で答える**：問題の意味・ヒントからタイ語を入力し、「文字の答えを確認」を押します。前後の空白を除いた完全一致で綴りを確認し、見本・IPA・理由を表示します。発音の判定ではありません。
2. **声で確かめる**：見本の合成音声とIPAを確認してから「録音を始める」を押し、ブラウザでマイクを許可します。最大20秒・5MB。録音を止めて再生し、見本と交互に聞けます。「録音を削除」や方法の切替・画面移動で破棄されます。
3. **音声認識（任意・参考）**：対応ブラウザだけで利用できます。開始前の説明を読んで「音声認識を始める」を押すと、タイ語の認識を試み、約9秒で終了します。音声はブラウザ提供元へ送信される場合があります。表示するのは認識された文字列との一致で、発音・声調・信頼度を採点しません。一致しても正確な発音の証明にはなりません。

Macでタイ文字を入力するには「システム設定 → キーボード → テキスト入力 → 編集 → ＋」からタイ語を追加し、入力メニューで切り替えます。マイクはHTTPSまたは `http://localhost:3000` で利用してください。音声・録音・認識の非対応、マイク拒否、認識エラーの場合も、文字入力や既存の解説・クイズで学習できます。TTS・録音・音声認識は同時に実行しません。

録音機能はアプリから音声を送信せず、この画面のメモリ内で扱います。一方、音声認識と端末の合成音声には、ブラウザ・OSの提供元への通信が発生する場合があります。入力・録音・認識結果をlocalStorageやサーバーへ保存する機能はありません。詳細と確認範囲は [入力・録音練習仕様](docs/LESSON_OUTPUT_SPEC.md) と [検証結果](docs/VALIDATION.md) を参照してください。
